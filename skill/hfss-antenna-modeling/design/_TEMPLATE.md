- **基板**:εr = ?, h = ?(无基板/自由空间结构写"无")

## 设计公式 / λ 归一化尺寸 ★核心
**一套服务任意频率**——优先给**闭式公式**(自动含 εr、频率);没有闭式就给**按 λ₀ 归一化的关键尺寸常数**(注明对应 εr,换 εr 不通用)。

- 关键尺寸 1 = …(公式或 `x/λ₀ = 0.xx @ εr=?`)
- 关键尺寸 2 = …
- 地板/反射板/腔体尺寸 = …(功能件,别省)

> λ₀ = c / f₀(自由空间波长);λg = λ₀/√εeff(介质内)。缩放到新频率:尺寸 ∝ 1/f。

# 渐变槽天线（Vivaldi / LTSA / CWSA）设计卡片

> 金属层上开一条向端部张开的槽，波沿槽行进、边行边辐射的**端射行波天线**。
> 卖点：**平面结构做出 E/H 面对称的端射波束 + 超宽带（Gibson 原型可用带宽 5:1）+ 中高增益（10–17 dB）**；
> 代价是**电长度大**（L ≥ 2.6λ₀，常用 4–10λ₀），且**对基板厚度极其敏感**。
> 典型场景：反射面/透镜馈源、成像阵、相控阵单元、UWB。
> 关联经验：`../knowledge/` 暂无本拓扑条目（首次建模后补）
> **⚠️ 原文在 [`../papers/INDEX.md`](../papers/INDEX.md) 第 3 条，本卡全部内容蒸馏自 Yngvesson 1985。**

> **⚠️ 这张卡给的是"判据"不是"照抄的尺寸表"。**
> 原文是设计准则型文献：长度↔波束宽度曲线、基板厚度容许区间、口径下限、馈点阻抗。
> **它没有 PCB 可用的馈电结构**（用的是波导-fin line 过渡），也没有对踵/平衡对踵/侧壁 corrugation。
> 那几样要另找文献，别从本卡反推。

## 适用范围
- **拓扑类别**：三种槽形，共用同一套判据 ——
  - **Vivaldi**：指数张开，`y(x) = ±A·e^(px)`。形状效应**很大**（p 变化影响显著）
  - **LTSA**：直线张开，开口角 α。形状效应**很小**（α 变化影响温和）
  - **CWSA**：指数馈电渐变段 + 等宽槽 + 端部短渐变
- **已验证频段**：2–94 GHz（判据按 λ₀ 归一化，可线性缩放；换频时**基板厚度必须按同一因子一起缩放**）
- **基板**：εr 1.05–10 都验证过，但**厚度受式(1)强约束**，见下
- **馈电**：原文为波导→fin line→槽线过渡（Fig. 2, p3）。**馈点阻抗 ≈80Ω，不是 50Ω**

## 设计公式 / λ 归一化尺寸 ★核心

### ① 长度 → 波束宽度 / 方向性（Table I, p3；引自 Zucker）

| | 最大增益档 | 低副瓣 / 宽带档 |
|---|---|---|
| 方向性 D (dB) | `10·log(10·L/λ₀)` | `10·log(4·L/λ₀)` |
| 3dB 波束宽度 (°) | `55/√(L/λ₀)` | `77/√(L/λ₀)` |
| 最优相速比 | `c/v_ph = 1 + 1/(2L/λ₀)` | — |

**实测落点**：多数 TSA 落在**低副瓣曲线上或低它 1–2 dB**；短 CWSA 最接近高增益曲线。典型 10–17 dB。
→ 给定波束宽度目标，用这两条式子反解 L/λ₀，就是起手长度。

### ② 基板厚度 ★头号约束（式(1), p4 + 结论, p8）

```
t_eff/λ₀ = (√εr − 1) · t/λ₀
```
**推荐区间：0.005 ~ 0.01**（对应 L = 4–10λ₀）。**短 CWSA（2.5–4λ₀）可稍厚。**
> ⚠️ 二手资料常写成 0.005~0.03 —— 那是把下表"高增益/不对称"两档也算进去了，**不是原文推荐值**。

Table II（p6）实测分档，选基板直接查这张：

| t_eff/λ₀ | 实测行为 | 实例 |
|---|---|---|
| .0025 / .0068 | **低副瓣，标准行波** | Duroid 0.14mm@10G(εr2.33)；Kapton 0.025mm@94G(εr3.5) |
| .014 / .023 | 增益提高，副瓣抬升 | Kapton 0.05mm@94G；Duroid 0.14mm@94G |
| .018 ~ .028 | **E/H 面不对称**；<4–5λ₀ 波束宽度暴涨；长天线 H 面反而变宽 | Kapton 0.076mm@94G；Duroid 1.5mm@10G；Duroid 0.5mm@35G；Epsilam-10 0.25mm@10G |
| .021 | 例外：Styrofoam 25.4mm(εr1.05) 仍表现为低副瓣 | 极低 εr 时该判据偏保守 |

**E 面比 H 面对厚度敏感得多**（H 面曲线几乎不动，E 面先劈）。

### ③ 口径宽度下限（式(2), p5）
```
λc = 2W        // W = 口径（张开末端）宽度
```
口径 W 小到 λ/2 量级就不再是宽带行波天线。
- α=11.2° 的 LTSA：λc=λ₀ 对应 **L/λ₀ = 2.6 → 这是长度绝对下限**，靠近它波束宽度急剧上升
- **高增益 LTSA 典型 λc/λ₀ = 3–4**（即 W = 1.5–2λ₀）—— 起手取这个
- 反例：W≈λ₀/4、L≈λ₀ 的设计根本不是行波天线

### ④ 形状
- **Vivaldi**（式(3), p5）：`y(x) = ±A·e^(px)`，x/y 单位 mm。A 定馈端槽宽，p 定张开快慢。
  **⚠️ 原文没给 p 的推荐值**，只给了方向性判断：
  - 要**频率无关的波束宽度** → 让指数**张得快**（有效辐射长度 << 物理长度）。Gibson 原型 L≈30mm、W≈16mm（W/L≈0.53），3.25:1 带内 HPBW 30–45°，5:1 可用
  - 要**给定长度下的最大增益** → 张得慢
  - → **p 必须扫参**，这是 Vivaldi 唯一的主自由度
- **LTSA**：**α = 11.2° 是原文主力值**（E/H 面波束宽度大致对称）。α↑到 16.4°：H 面几乎不变，**E 面变窄**（要对称就别加）
- **CWSA**（式(4), p7）：等效长度 `L = 10 + Ls + 0.75·Lt`（mm，对应 Fig. 2 那套 20mm 馈电渐变）。
  等宽槽 W 取 1–5mm（<λ₀）辐射效率很差；W≈λ₀ 才正常。**L/λ₀ > 5~6 副瓣暴涨、主瓣劈裂**

### ⑤ 馈点阻抗（V. Impedance, p7–8 + Fig. 12）
无介质/薄介质 LTSA 馈点阻抗 **≈ 80Ω**，4 GHz 以上基本与频率无关（Carrel 保角映射理论 + 实测吻合）。
薄介质（0.13mm）不明显改变它。远离馈电区的槽形状对阻抗影响很小。
→ **HFSS 里别默认扔个 50Ω 端口就算完**，要么端口设 80Ω，要么加变换段。

## 起手 → 调匹配（哪个自由度控什么）
1. **定 f_low** → 口径 `W = 1.5~2·λ₀`（即 λc/λ₀ = 3–4）
2. **定波束宽度目标** → 用 ① 反解 `L/λ₀`（下限 2.6，常用 4–10）
3. **选基板** → `t ≤ (0.005~0.01)·λ₀/(√εr − 1)`。这一步定死后再动几何
4. **形状**：LTSA 取 α=11.2°；Vivaldi **扫 p**（`create_parametric_sweep`，主自由度）
5. **馈电单独设计**，按 80Ω 做变换
- **控波束宽度/增益**：L/λ₀（主）、基板 t_eff（次，且会连带改副瓣与 E/H 对称性）
- **控低频截止**：口径宽度 W（λc = 2W）
- **控 E/H 面对称性**：基板厚度 + α；E 面永远是先坏的那个
- **控带宽形态**：Vivaldi 的 p —— 张得快=宽带、张得慢=高增益
- **推荐扫参**：`p`（Vivaldi）或 `α`（LTSA）× `L/λ₀` 两维；基板厚度按 ③ 先锁死别一起扫

## 报告性能（对标用）

| 指标 | 报告值 |
|---|---|
| 中心频率 | 8 / 10 / 12.4 / 31 / 35 / 94 GHz 均有实测 |
| 方向性 | 10–17 dB（落在低副瓣曲线或低 1–2 dB） |
| 3dB 波束宽度 | 介于 `55/√(L/λ₀)` 与 `77/√(L/λ₀)` 之间 |
| 波束效率 | 50–70%（10dB 波束宽 ≈60° 时），与普通波导馈源相当 |
| 输入阻抗 | ≈80Ω，4GHz 以上与频率无关 |
| Gibson 原始 Vivaldi | HPBW 30–45° over 3.25:1；可用带宽 5:1 |
| 副瓣 | 比波导喇叭略高；天线越长副瓣越高 |

## 建模配方要点
- **不是谐振天线，是行波天线**：别用"调谐振频率"的思路调它。带宽由 W（低端）和馈端槽宽（高端）两头卡，中间靠 p/α 平滑过渡。
- **求解域要留够**：端射天线主瓣沿 +x，辐射边界离口径至少 λ_low/4，且**要包住整个物理长度**（4–10λ₀ 不短）。
- **换频缩放**：尺寸 ∝ 1/f，**基板厚度必须同因子缩放**，否则 t_eff 直接跑出区间（原文用 Duroid 0.14mm@12.4G 缩到 Kapton 0.025mm@94G，厚度没缩准，靠把长度从 10.5λ₀ 微调到 10λ₀ 补回来）。
- **本卡不覆盖**：微带→槽线过渡 / 径向短截线 / 圆腔尺寸、对踵(Gazit 1988)与平衡对踵(Langley 1996)、侧壁 corrugation、阵列互耦。要做这些先补文献进 `../papers/`。

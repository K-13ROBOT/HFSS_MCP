# 磁电偶极子(ME dipole)设计卡片

> 平面电偶极子(串联谐振)+ 短路 λ/4 贴片磁偶极子(并联谐振)等幅同相合成的互补天线。
> 卖点:**宽带(40–50%)+ 带内增益/波束宽度极稳 + E/H 面方向图一致 + 低交叉极化低后瓣**;代价是高度 ≈0.25λ₀。
> 典型场景:移动基站(单/双极化)、UWB、60GHz。
> 关联经验:[../knowledge/magneto-electric-dipole.md](../knowledge/magneto-electric-dipole.md) ←建模/排错时配合读
> **⚠️ 原文在 [`../papers/INDEX.md`](../papers/INDEX.md),本卡全部内容蒸馏自其中的 Handbook 那篇。**
> 下表每个变体只有一行,**符号含义无法从这一行反推**(实战踩过:照"单馈 CP"那行猜 L₁/L₂/S₁/S₂ 的指向,连猜三种解读都是错的)。
> **选定要建哪个变体后,先按 papers/INDEX.md 跳到原文那张图 + 那张尺寸表看完再动手。**

## 适用范围
- **拓扑类别**:互补天线(电偶极子 + 磁偶极子)。磁偶极子可为短路 λ/4 贴片 / 三角环 / 矩形环 / 过孔阵。
- **已验证频段**:1.7–70 GHz(卡内尺寸按 λ₀ 归一化,同拓扑可线性缩放,尺寸 ∝ 1/f)。
- **基板**:原型**无基板(空气)**,纯金属结构 → 归一化尺寸与 εr 无关,缩放最省心。介质加载型与毫米波印刷型见下表。
- **馈电**:Γ 探针(基准)/ T 探针 / 方形贴片耦合 / 直连馈电 / L 探针+过孔。

## 设计公式 / λ 归一化尺寸 ★核心

### 原型(Luk & Wong 2006):四步设计法
1. 平面电偶极子:**L = 0.25λ₀(单臂长,总长 2L≈0.5λ₀)**,**W = 0.5λ₀**
2. 短路 λ/4 贴片:**H = 0.25λ₀**,**W = 0.5λ₀**,**S ≈ 0.14λ₀**(两振子臂间隙 = 贴片等效基板厚度)
3. 地板:**G ≈ λ₀**
4. Γ 探针:第一段与相邻竖直壁构成 **50Ω 空气微带线**;最后扫 **a、b** 调匹配

实测原型(2.5GHz)归一化:L 0.25 / W 0.50 / S 0.14 / H 0.25 / G 1.33 / a 0.08 / b 0.18 / 探针宽 f 0.04(λ₀)

> λ₀ = c/f₀(自由空间)。原型为空气结构,换频率**所有尺寸同比 ∝1/f** 即可;介质加载/印刷型换 εr 不通用。

## 起手 → 调匹配(哪个自由度控什么)
- **控低频谐振 f₁**:电偶极子长度 **L**(L↑→f₁↓,f₂ 不动)
- **控高频谐振 f₂**:短路贴片电长度 **H**(H↓→f₂↑,f₁ 不动)
- **控阻抗匹配**:Γ 探针 **a**(耦合段)与 **b**(补偿短截线)。a↓→f₁ 下移且带内 SWR 变差;b↓→f₂ 上移且低频匹配变差
- **控增益/后瓣**:地板 **G**(对匹配几乎无影响);要更低后瓣改盒形反射板 Gh≈0.17–0.25λ₀
- **控隔离(双极化)**:两正交探针的高度差
- **推荐扫参**:先 `L`(±10%,5 点)与 `H`(±15%,5 点)把双谐振咬合,再 `a`、`b`(各 ±30%,5–7 点)压 S11。参扫注意事项见 [../knowledge/_optimization.md](../knowledge/_optimization.md)

## 建模配方要点
- 金属振子/壁/地板用零厚度面 + PerfectE(见 `../knowledge/_general.md`);Γ 探针有体积,用 box/polyline 实体。
- **探针不与振子电接触**(直连馈电型除外),别 unite。
- 壁与壁之间的地板是短路贴片的短路端,**不能挖空**。
- 复现时按 `SKILL.md §0` 先出"结构理解表 + 层叠表"给用户确认——ME dipole 的 3D 折叠视图透视失真严重,拓扑最易建歪。

## ★ 双馈 CP 四板四柱 ME 偶极子(本人验证,Ku 波段 15.5GHz)

> 空气金属结构,纯 λ₀ 归一化,换频率同比 ∝1/f。HFSS 2025.2 全波验证,6 项指标全达标。
> **拓扑出处**:Li & Luk 2012「简化正交 Γ 探针」双极化天线(原文 **Fig. 33 / p25**,设计指南在 p24–25),
> 按原文说法加「Wilkinson + 90° 移相器」即成 CP(Li & Luk 2013c)。**建之前务必先看原图**,见 [`../papers/INDEX.md`](../papers/INDEX.md)。

### 为什么用这个拓扑做 CP(选型理由,别绕弯路)

同样是双馈,**十字缝连续壁**版和**四板四柱**版差别巨大,关键在**探针能不能居中**:
- 连续壁版:缝中心区没有壁可参考,探针只能偏置 ≈0.11λ₀ → 每个极化都被偏心馈电 →
  单元波束各偏轴 12° → 合成后 **HPBW 两主面差 18°**,且两口互耦大(≈−17dB),被迫用 **2:1 不等分电桥**。
- 四柱版:柱子窄(0.10λ₀),两条正交缝在中心交叉,**探针在交叉处耦合=中心馈电** →
  **HPBW 两面差 0.5°**,等幅馈电即可。实测对比见下表。

| | 连续壁两探针 | **四板四柱** |
|---|---|---|
| HPBW 两面差 | 18° | **0.5°** |
| 带内最大 AR | 2.42 dB | **0.28 dB** |
| 交叉极化 | 21.3 dB | **38.6 dB** |
| 前后比 | 37.1 dB | **50.5 dB** |
| 增益 | 7.96 dBic | **8.62 dBic** |
| 馈电网络 | 2:1 **定制不等分**电桥 | **等分** + 固定移相 |

### 归一化尺寸(λ₀ = c/f₀;@15.5GHz 时 λ₀=19.34mm)

**辐射体**(与原文设计指南几乎一致,验证了指南可直接用):

| 符号 | 含义 | λ₀ | @15.5GHz | 原文指南 |
|---|---|---|---|---|
| Lpl | 顶板边长(方,四块全等) | **0.168** | 3.25 mm | 0.20(我调低以对中频率) |
| Wpo | 柱截面(方) | **0.100** | 1.93 mm | 0.10 ✓ |
| Sg | 相邻柱间缝宽 | **0.050** | 0.97 mm | 0.05 ✓ |
| Hpo | 柱高(=λ/4) | **0.250** | 4.84 mm | 0.25 ✓ |
| Gb | 盒形反射板底边 | **0.800** | 15.47 mm | 0.8 ✓ |
| Ghw | 盒壁高 | **0.250** | 4.84 mm | 0.25 ✓ |

**布局**:四柱内角在 (±S/2, ±S/2),两条正交缝在中心交叉;每块顶板压在自己柱子上(内角对齐柱内角),
顶部外廓 2(S/2+L) = 0.386λ₀。

**两根 Γ 探针**(零厚度 PE 片,**探针1 整体在 x=0 平面、探针2 在 y=0 平面**,各自呈平面「⊓」形):

| 符号 | 含义 | λ₀ | @15.5GHz |
|---|---|---|---|
| Fw | 竖直段带宽(柱间**带状线**,两侧柱面当地) | 0.057 | 1.1 mm |
| Fwa | 水平段 z 向厚度(**可小于 Fw**,阶梯宽度) | 0.041 | 0.8 mm |
| Fh1 / Fh2 | 探针1 / 探针2 高度(**必须不等**) | 0.233 / 0.171 | 4.5 / 3.3 mm |
| F_Δ | 两水平段高差 = Fh1−Fh2 | 0.062 | 1.2 mm |
| Fry / Fry2 | 探针1 / 探针2 耦合段半长(**分开给**) | 0.088 / 0.072 | 1.7 / 1.4 mm |
| Fd / Fd2 | 探针1 / 探针2 短截线长(**分开给**) | 0.176 / 0.140 | 3.4 / 2.7 mm |
| zj | 竖直段离地高度(**不可为 0**,见下) | 0.016 | 0.3 mm |

**同轴**:空气填充 50Ω,内 r=0.196mm / 外 r=0.45mm(b/a=2.30)。馈电点 P1 (0, Fry)、P2 (Fry2, 0)。
⚠️ **孔径受缝宽卡死**:必须 `outer_radius < Sg/2`。Ku 波段这就意味着 0.4mm 级的孔、0.2mm 级的针,
选型时对照 0.047" 半刚一类的实物规格,**确认买得到再往下做**。

**约束(写进变量表达式,别靠人工检查)**:
- `Fdel = Fwa + 0.4mm` —— 保证两水平段永不相撞;
- `Fd2 = Fh2 - 0.6mm` —— 保证探针2 短截线永远在地板之上(探针2 更矮,共用 Fd 必穿地);
- `zj > 0` —— 竖直段抬离地板,否则片宽一旦 ≥ 孔径就被地板短路,且 Fry 无法自由扫。

### 馈电网络(关键)

**RHCP:P1 = 1W ∠0°,P2 = 1W ∠+60°**;LHCP 用 **∠−120°**。

- **等幅**即可(不需要不等分电桥)——这是四柱中心馈电相对连续壁版的主要工程收益。
- 为什么是 60° 不是 90°:两根探针**不等高**带来一个 **+30° 的结构固有相位偏置**,
  实测**全带恒定**(AR 曲线在 13.5–17.5GHz 只波动 0.15dB),所以补一个**定值**即可 ——
  90° 电桥后加 ≈1.6mm 线长(30°@15.5GHz),或直接按 60° 设计移相器。
- ⚠️ **该偏置不随旋向翻转**:左旋 −120°、右旋 +60°,不是简单取反。换旋向时必须重测。

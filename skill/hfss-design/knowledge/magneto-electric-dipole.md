# 磁电偶极子(ME dipole / 互补天线)

平面电偶极子 + 短路 λ/4 贴片(磁偶极子)+ Γ 形探针 + 反射板。基座天线主力拓扑。
经验/机理在本篇;**具体尺寸与性能数据**见 [../design/magneto-electric-dipole.md](../design/)。

## 机理:两个源等幅同相合成,不是"反射板背衬偶极子"
- 本质:电偶极子 E 面 8 字 / H 面 O 字,磁偶极子 E 面 O 字 / H 面 8 字;等幅同相叠加后归一化方向图 F(θ)=(1+cosθ)/2 —— **E/H 面完全一致、θ=180° 理论后瓣为零**。这是判断"磁偶极子到底有没有被激励起来"的唯一硬指标。
- 现象:建完 E 面/H 面波束宽度明显不等、后瓣抬高 → 磁偶极子没起作用,天线退化成普通反射板背衬电偶极子。
- 原因:竖直金属壁太窄(文献实验:壁宽减到 10mm 即退化)、壁没真接到地、或壁间那块地被挖掉。
- 解法:竖直壁宽度要和振子同量级(≈0.5λ₀);建完 `get_object_bbox` 确认壁底 z 落在地板上;取方向图必须**同时看 E 面和 H 面**,只看一面看不出退化。

## 两个谐振分别归 L 和 H 管,一个变另一个不动
- 现象:宽带做不出来 / S11 中间冒起一个洞(双谐振没咬合),不知道该动哪个尺寸。
- 原因:低频谐振由**平面电偶极子长度 L** 决定(L↑→f₁↓,f₂ 纹丝不动);高频谐振由**短路 λ/4 贴片的电长度 H** 决定(H↓→f₂↑,f₁ 不动)。两者近乎完全解耦。等效电路上电偶极子是串联谐振、贴片是并联谐振,并联后虚部抵消要求 CdLd=CpLp 且 Rd²=Ld/Cp —— 即**两者同频 + 电偶极子输入电阻取特定值**,这才是 40–50% 带宽的来源。
- 解法:带宽不够/中间有洞 → 调 L 和 H 让两个谐振互相靠拢咬合,**不要去动地板、也不要指望探针把带宽拉宽**。先用 L 定低端、H 定高端,再用探针调匹配。参见 `_optimization.md`「双谐振宽带匹配」。

## 匹配只归 Γ 探针的 a/b 管,不归辐射体尺寸
- 现象:S11 压不下去,想改振子/壁尺寸去凑。
- 原因:Γ 探针三段各司其职——**第一段**与相邻竖直壁构成 **50Ω 空气微带线**(不是随便一根引线,特征阻抗要算);**第二段(长 a)**跨过振子间隙把能量耦合进天线,同时引入感抗;**第三段(长 b)**是与竖直壁构成的**开路微带短截线**,专门补偿第二段的感抗。
- 解法:匹配只扫 a 和 b。规律:a↓ → 第一谐振下移且带内 SWR 变差;b↓ → 第二谐振上移且低频匹配变差。改 a/b 会轻微牵动谐振,所以顺序是「先 L/H 定频 → 再 a/b 调匹配 → 必要时微调 L/H 回频」。

## 探针与振子**不电接触**,建模别 unite
- 现象:把 Γ/T/L 探针和振子合并成一体,S11 完全不对。
- 原因:Γ 探针、T 探针、方形贴片耦合探针全是**邻近耦合(proximity-coupled)**馈电,探针悬空不碰振子。只有"直连馈电"(loop 型 ME dipole)才真接触。
- 解法:探针建成独立对象,靠间隙耦合;间隙尺寸从参数表抽。附带影响:耦合馈电**不是直流接地**的,户外基站防雷场景论文会改用直连馈电,这也是 loop 型 ME dipole 存在的理由之一。

## 地板只管增益和后瓣,不管匹配——别拿它调 S11
- 现象:S11 不好就想加大/改地板;或者地板改了半天匹配纹丝不动。
- 原因:文献参数研究明确:G 增大 → 增益提高、后瓣下降,但**对输入匹配几乎无影响**。
- 解法:G 按 ≈λ₀ 起手,只作为增益/后瓣的调节量。特别注意两点:①**壁与壁之间那块地板是短路 λ/4 贴片的短路端,是天线的一部分,绝对不能挖掉或省略**;②理想互补天线"零后瓣"的结论**不含地板绕射**——完全去掉地板实测后瓣仍有 −7dB,天线和地板必须当作一个整体来设计。要进一步压后瓣/稳增益就换**盒形反射板**(侧壁高 Gh≈0.17–0.25λ₀)。

## H 是"电长度 λ/4",不是"物理高度"——折叠/环形结构里两者不等
- 现象:照着降高度的论文建,把 H 直接当成天线总高,谐振全错。
- 原因:磁偶极子要求短路贴片**电长度**为 λ/4。折叠 ME dipole 里天线物理高度 = 2h₁+h₃,而短路贴片的电长度 = 2h₁+2h₂+h₃ —— 靠折叠把 λ/4 的路径"藏"在矮结构里。
- 解法:读降高度类论文时先分清哪个尺寸是物理高度、哪个是沿壁展开的电长度,自检:沿金属壁把路径展开累加应 ≈0.25λ₀。降高度的代价是共性的:**越矮 → 带宽越窄、工作频带整体上移**。

## 降高度四条路线及各自代价(选型用)
- 原型高度 ≈0.25λ₀ 是 ME dipole 最大短板。四条通用路线:
  1. **折叠竖直壁**:保持电长度 λ/4,高度可到 ≈0.17λ₀。代价:带宽变窄、频带上移,结构变复杂。
  2. **介质加载**(壁间填 εr>1):高度 ∝1/√εr,εr=2.65 时到 ≈0.16λ₀。代价:短路贴片易激起**高次模 → 交叉极化恶化到 ≈−18dB**(原型可做到 −25dB 以下)。
  3. **换磁偶极子形态**(三角形/矩形环代替短路贴片):高度 ≈0.16λ₀ 且性能保持好。三角环取近等边(θ=60°)、周长≈λ₀/2;矩形环设计约束是 **2(M₁+M₂)≈0.5λ₀**。代价:必须配直连馈电,而直连馈电没有补偿段,**要求振子间隙极小(S≈0.02–0.05λ₀)**,加工难;且高频最大增益会偏离法向。
  4. **换互补对(短路领结贴片 + 电偶极子等)**:可低到 <0.1λ₀。注意这类结构里**电偶极子只贡献增益/压后瓣/稳方向图,带宽基本由短路贴片自己给**(去掉电偶极子带宽几乎不变)——别误以为是两个谐振咬合。
- 共性判据:高度换带宽,任何降高度手段都要重新核对 E/H 面一致性和交叉极化。

## 馈电形态的权衡(选哪种探针)
- **Γ 探针**:基准,交叉极化与后瓣最低,但结构最难加工。
- **T 探针 / 方形贴片耦合探针**:把第三段换成横向贴片,带宽比 Γ 更宽,但**后瓣和交叉极化都更高**;T 型可整体印在单层 PCB 上,是毫米波(60GHz)首选。
- **直连馈电**(同轴段 + 沿振子臂的空气微带,跨间隙直连另一臂):直流接地可防雷,与环形磁偶极子一起兼作**折叠 balun**;缺点见上条(间隙必须极小、高频波束偏斜)。
- **L 探针 + 过孔阵**:毫米波片上做法——用一排镀通孔代替金属壁构成短路 λ/4 贴片,基板厚度选 ≈λg/4。选 Duroid 类低损耗基板,FR4 在该频段不可用。

## 双极化:一个极化激励时,四根柱子等效成两个磁偶极子
- 现象:双极化 ME dipole 的拓扑(四块方板 + 四根柱 + 两根正交探针)看不懂谁是磁偶极子,建歪。
- 原因:激励一个极化时,**每根柱 + 相邻柱 + 其间地板** = 一个短路 λ/4 贴片;四个这样的贴片两两并排各等效成一个磁偶极子,两个磁偶极子的**矢量和垂直于**由对角两块板构成的电偶极子 —— 互补条件仍成立。
- 解法:四根柱必须均匀布置、留出两条正交间隙,探针放在间隙交叉处耦合。**两根正交探针要故意做成不等高度**(文献即如此),这是拉开隔离度的关键;代价是两端口工作频带略有差异。仿真必须同时看 S11/S22/S21,别只盯一个口(见 `flow/tuning.md`「多端口跷跷板」)。

## 文献符号最容易混的三个:L / W / S
- **L 通常是单臂长 ≈0.25λ₀**,整个电偶极子长 = 2L ≈ 0.5λ₀(半波)。看到 "L=0.25λ₀" 别当成整个偶极子长。
- **W ≈0.5λ₀ 是横向宽度**,同时也是竖直壁(短路贴片)的宽度——原型里振子和壁同宽。但双极化设计里 W 变成单根柱的宽度(≈0.10λ₀),含义完全变了,必须按该篇的图重新对号。
- **S 是两振子臂之间的间隙**,同时就是短路 λ/4 贴片的"等效基板厚度"(原型 ≈0.14λ₀,约十分之一波长量级)。它不是振子宽度,也不是离地高度。
- 遵循 `flow/reproduce-paper.md`「所有尺寸数字只从参数表/正文抽,绝不在图上量」:ME dipole 的 3D 折叠视图透视失真尤其严重。

## 典型性能包络(用来判断"建对了没有")
- 单极化原型:−10dB 带宽 **40–50%**,增益 **≈8 dBi 且带内起伏 <±0.5dB**,E/H 面波束宽度基本相等,交叉极化 <−20dB,前后比 >20dB。
- 仿真结果若带宽只有百分之几 → 多半是两个谐振没咬合或磁偶极子没起来;若增益带内大起大落 / 方向图随频率乱变 → ME dipole 的核心卖点没实现,回去查 E/H 面一致性。
- 想要 UWB(>90% 带宽)必须换形(梯形/领结振子、折叠短路贴片、差分馈、盒形反射板),原型拓扑到不了。

## 缝内探针只激励得起与该缝正交的那一个模——单馈 CP 必须"微扰加对角、馈电走轴向"
- 现象:做单馈 CP,四板十字缝结构怎么改板形都出不来圆极化,boresight RHCP/LHCP 只差零点几 dB(AR 25~27dB,实为线极化)。
- 原因:探针放在一条缝里,驱动的就是跨这条缝的那一个模(缝沿 y → 驱动 Ex),另一个正交模投影为零,压根没被激励。结构本身多不对称(哪怕做成 C4 风车)都救不了——**C4 旋转对称要配顺序相位馈电才出 CP,单点馈电的 C4 结构仍是线极化**。
- 解法:两者必须正交安排。要么**微扰加在两条对角线上(切角/钩形条)、馈电走轴向(缝内直探针)**——此时两个简并模是 ±45° 对角模,轴向驱动对二者各成 45°,等幅激励;要么反过来(微扰轴向、馈电对角)。**同向安排必然失败**。
- 附带:判断"两个模到底激励起来没有",用 boresight 的 `polarization='theta'` 与 `'phi'` 两次 get_radiation_pattern 取幅度比,再用 RHCP/LHCP 功率比反解相位差 —— 幅度和相位分开看,才知道该调哪个。

## 单馈 CP 的 90° 相位差归"能改短路贴片电长度"的自由度管,顶板尺寸权限很弱
- 现象:对角两对顶板尺寸比从 1.74 加大到 3.24(几乎翻倍),两模相位差只从 33° 挪到 37.6°,AR 才 10.7→9.4dB,增益倒掉了 2dB。
- 原因:ME 偶极子的谐振主要由**公共的壁高 H(短路 λ/4 贴片电长度)**定,四块顶板共用同一个 H,所以改顶板平面尺寸只能微调各自的电偶极子分量,对模间相位杠杆很小。
- 解法:要劈裂两个对角模的相位,得动**能改变各自短路贴片电长度**的东西——文献用的**钩形条(从板边往下折的竖直条)**正是干这个的,实测 1.5mm 钩条贡献 6.3° 相位,单位杠杆比顶板尺寸翻倍还大。**钩条长度存在最优值**(实测过长后 AR 反而恶化、增益持续下降),要扫参找拐点,别单调加大。
- 提示:低 Q(宽带)是把双刃剑——Q 越低轴比带宽越宽,但要凑够 90° 相位所需的劈裂量也越大,结构会被撑大、增益下降。单馈 CP 在 ME 偶极子上是"相位难凑、带宽好拿";双馈(正交双探针 + 90° 电桥)把相位交给馈电网络保证,是更稳的工程路线。

## Γ 探针耦合端的容抗必须与天线电阻同量级,否则端口看到的是近似短路
- 现象:探针建好、几何自检也没问题,但 Zin 只有 1Ω 上下(近似短路)、S11 全频段 −0.3dB,像是天线完全没被激励。
- 原因:探针夹在两面**底部都接地**的竖直壁之间,与两侧壁各形成一个电容,**串联**后就是馈入天线的耦合电容。耦合面积小/间隙大时串联容抗可达数百欧姆,远大于天线的几十欧姆 → 严重欠耦合,天线电阻经这个大容抗变换到端口后只剩 1Ω 量级。
- 解法:先按 C=ε₀A/d 估**串联耦合容抗**,让它落到与天线电阻同量级(≲50Ω 量级)再建。注意竖直段与相邻壁的电容是**传输线的分布电容(由 50Ω 决定,W/h≈5,不可自由改)**,真正能调的是**耦合端的面积与间隙**。诊断手法:从 Zin 反推探针顶端负载阻抗(用传输线公式退回去),看实部是不是小得离谱——是就是欠耦合,不是匹配问题。

## 十字缝四板 ME 偶极子做单馈 CP:两个正交模共用同一套壁,相位差有硬上限(~40°),凑不到 90°
- 现象:按"对角微扰 + 轴向馈电"的正确配置做单馈 CP,AR 能从 27dB 一路压到 ~8dB,但**再怎么加大微扰都卡在 8dB 左右下不去**。反解两模相位差始终在 40°±3°,而 CP 需要 90°。
- 实测(15.5GHz 附近,三个独立自由度各自推到极限):

  | 自由度 | 变化幅度 | 相位差 | min AR |
  |---|---|---|---|
  | 基线(仅对角板尺寸比 1.74) | — | 33° | 10.66 dB |
  | 对角尺寸比 1.74→3.24 | ≈2× | 37.6° | 9.37 dB(且增益 −2dB) |
  | 钩形条 Lh 0→2.5mm | 0→0.5H | 40.3° | 8.70 dB |
  | 钩条数 1→2 条/板 | 2× 加载 | 42.7° | 8.15 dB |

  几何量翻倍只换来个位数的度,离 90° 差 47°,需要再放大一个数量级——不可能。
- **原因(关键)**:十字缝四板结构里,磁偶极子是**缝两侧的壁构成的短路 λ/4 贴片**,而**两个正交(对角)模用的是同一套缝、同一套壁、同一个壁高 H**。也就是说结构里**只有一个谐振系统**,所谓"两个简并模"只是对它的两种正交激励方式,天然同相。顶板尺寸/钩形条这类微扰改不了这个事实——它们只能在这一个谐振上做小扰动,给出几十度就到顶。单馈 CP 靠简并模劈裂,前提是**存在两个可独立调谐的谐振器**,这个拓扑不满足。
- **解法**:要么换成**两套可分离的谐振系统**(如两对独立的短路贴片、不同壁高),要么让 90° 不由结构给而**由馈电给**——双馈(正交双探针 + 90° 电桥)或单馈加延迟线(交叉偶极子那套)。判据:动手前先问"这结构里到底有几个独立谐振器?"——只有一个就别指望单馈简并模劈裂做出宽带 CP。
- 附带正面结论:该拓扑的**轴比带宽能力没问题**——最优点上 AR 曲线在 14.5–16.5GHz 内只起伏 1.5dB 且峰值正对中心频率。卡住的纯粹是电平(相位),不是形状也不是带宽。所以换成双馈把相位补上后,带宽是够用的。

## Γ 探针第三段(补偿短截线)太短等于没有:要到 0.15λ 量级才开始消感抗
- 现象:知道"第三段补偿第二段的感抗",于是加了个短截线,但扫它只见输入电阻 R 变、感抗 X 纹丝不动,匹配卡在 VSWR 2.5~3。
- 原因:开路短截线的输入电抗 X = −Z₀·cot(βl)。l 很短时 cot 很大,|X| 是几百欧姆量级,相对天线的几十欧姆几乎是开路 —— **压根没接入电路**,只有寄生耦合在改 R。
- 解法:先估 βl。要让补偿量落到与待消感抗同量级(几十欧姆),l 至少要 **0.15λ 以上**(βl≳55°,cot≲0.7)。实测:l 从 0.05λ→0.09λ 时 X 几乎不动(只有 R 从 39→71Ω);加到 **0.15λ 时 X 才从 +53 掉到 +25Ω**、VSWR 2.59→2.05。
- 配套:`Fd` 这类短截线通常是 **R 和 X 的耦合旋钮**(两个一起动),单靠它凑不到 50+j0;要另找一个能单独压 R 的自由度(水平耦合段长度 a / 带条宽度),两个一起扫。

## 中心馈电型(四柱)ME 偶极子:抬高水平段**不是**耦合旋钮
- 现象:照搬"贴片型靠间距控耦合"的直觉,想用水平段离顶板的高度调输入电阻,扫下来 R 几乎不动(93.3→92.8Ω)。
- 原因:四柱结构里能量是从**两条缝的交叉点(中心)**注入的,水平段是靠**边缘场耦合到四块板的内角**,不是面对面交叠。所以"垂直间距"这个在贴片里管用的量,在这里几乎不改变耦合面积。
- 解法:改用**水平耦合段的长度**(Γ 探针的 a,即带条跨过中心的伸出量)当 R 的旋钮。

## 方向图不对称归**探针位置**管,不归馈电网络管——而探针位置由辐射体拓扑锁死
- 现象:双馈 CP 做出来两个主面 HPBW 差很多(实测 62.6° vs 44.7°,差 18°),想通过换馈电网络
  (电桥→延迟线→改幅度配比)去修,怎么改都没用。
- 原因:先分清两件事。**幅度配比只能缩放两个单元的贡献,改不了单元自身的方向图形状**——
  如果两个正交单元各自都是旋转对称的,任何配比合成出来仍然旋转对称;不对称只可能来自单元本身。
  实测确认:单端口激励时**每个单元的波束各自偏轴 12°**,且偏向"背离自己馈电点"的方向。
  根源是**每个极化被偏心馈电**:十字缝连续壁结构的缝中心区没有壁可参考,探针只能偏置 ≈0.11λ₀。
- 解法:换到**探针能居中**的拓扑。ME 偶极子里就是**四板四柱**版(Li & Luk 2012):柱子窄、两条正交缝在中心
  交叉,**探针走柱间带状线、在交叉处(中心)耦合**,能量从几何中心注入。实测 HPBW 两面差 **18° → 0.5°**,
  顺带交叉极化 21→39dB、前后比 37→51dB,而且不再需要不等分电桥。
- 判据:**先用单端口分别取方向图**,看每个单元自己偏不偏轴。单元就偏 → 是位置/结构问题,别在馈电网络上耗;
  单元不偏而合成偏 → 才是馈电幅相问题。

## 不等高双探针会带来一个"结构固有相位偏置":全带恒定、补定值即可、但**不随旋向翻转**
- 现象:双馈 CP 按理论加 90° 相位差,轴比却停在 4~5dB;而且这个 AR **全带几乎不变**(实测 13.5–17.5GHz 只波动 0.15dB)。
- 原因:两根正交探针为了拉开隔离**故意做成不等高**(文献要求),不等的电长度带来一个固定相位差。
  它是**几何**造成的,不是路径色散,所以**与频率无关**——这正是 AR 曲线平坦的原因。
- 诊断:AR 平坦 = 固定误差。等幅下由 AR 反解相位差 δ(AR_lin=(√(1+s)+√(1−s))/(√(1+s)−√(1−s)), s=sinδ),
  再用 `set_port_excitation` 补 (90°−δ)。实测偏置 +30°,补成 0°/+60° 后 AR 从 4.8dB → **0.28dB**。
  ⚠️ 先确认是相位而非幅度:**把幅度配比往两边各试一次**,若都变差,说明等幅已最优、问题在相位。
- ⚠️ **换旋向时该偏置不翻转**:左旋要 −120°、右旋要 +60°,不是简单取反(结构偏置固定为 +30°,
  合成相位需要 ∓90°,所以端口相位是 −90−30 与 +90−30)。**换旋向必须重测,别想当然取负。**

## 四柱型 ME 偶极子:盒形反射器是**谐振体的一部分**,不是被动地板
- 现象:照"地板只管增益和后瓣、不管匹配"的通则去缩小盒子,结果 `Gb` 从 9.7→8.0mm 时谐振点直接从
  15.5GHz 跳到 >19GHz,P1 塌到 −6.45dB。频率灵敏度实测约 **−1.3 GHz/mm**,是全设计最强的旋钮。
- 原因:通则的前提是"地板远大于辐射体"。这里盒壁离顶板边缘只有 0.265mm,壁与板构成的**侧向电容
  是谐振回路的一部分**,盒子尺寸直接进谐振条件。壁高 `Ghw` 同理(约 −0.63 GHz/mm)。
- 解法:把 `Gb`/`Ghw` 当**频率旋钮**用,别当"随便定的地板"。缩尺寸时必须同时用 `Hpo`(柱高)反向补偿
  才能把频率拉回原处;实测 `Gb` 与 `Hpo` 的等频率轨迹见下条。
- ⚠️ 连带教训:**扫参前先把 Sweep 频段开够**。用 12–19GHz 扫时谐振全顶在 19GHz 边界上,看不出真实失谐量,
  白白误判了两轮;开到 12–30GHz 才看清。

## `Ghw/Hpo ≈ 0.85` 是带宽甜点——别默认让壁齐柱顶
- 现象:第一轮结论是"盒子缩小则带宽必然崩",但那是在 `Ghw = Hpo`(壁齐柱顶)下测的。
- 实测:Gb=10.4/Hpo=6.5 时,`Ghw=Hpo` 只有 21.2% 的 −10dB 带宽,而 `Ghw=5.5`(=0.846·Hpo)有 **26.8%**。
- 解法:`Ghw` 单独留作自由变量(写成 `0.846*Hpo` 之类的比例式),缩尺寸前先在这个比例上找甜点,
  否则会把"配置没调好"误判成"拓扑到极限了"。

## HPBW 由**顶板尺寸 `Lpl`** 决定,不是地板、也不是壁高
- 现象:观察到 `Gb` 缩小时 HPBW 变宽,就下结论"波束宽度归地板管"。错。
- 原因:当时把 `Lpl` 写成了 `Gb/2-Sg/2-0.6mm`——`Gb` 一动 `Lpl` 跟着动,相关性是**假的**。
- 判据:做 `Lpl` 固定、只扫 `Gb` 的对照(overhang 扫描),HPBW 在 Gb=7.6→9.5 全程 **87–91° 基本不动**;
  `Ghw` 从 1.0→6.5mm 也只让 HPBW 走 78.6→83.8°。真正管用的是辐射体口径 `Lpl`。
- ⚠️ 通用教训:**扫一个变量前先查它是不是被别的变量的表达式引用了**,否则测的是复合效应,结论会指错方向。

## 双馈端口必须各有**独立的**短截线自由度
- 现象:两个端口的 −15dB 带怎么调都对不齐,总是一个进带另一个出带。
- 原因:`Fd2` 当初写成了 `Fh2-0.6mm` 的自动表达式,**P2 根本没有自己的调谐自由度**,只能跟着 P1 走。
- 解法:把 `Fd2` 解绑成独立字面量。解绑后立刻出结果:`Fd=4.6/Fd2=4.4` 下 P2 的 −15dB 带做到
  14.37–16.63GHz(带内最差 −15.85dB)。**双馈设计里,每个端口的第三段短截线都要是独立变量。**

## 绝不在**失谐**的结构上读 HPBW/增益
- 现象:早期"Gb=8.0mm 时 HPBW 达到 98.6°"的结论是废的——那个变体的谐振点已经跑到 17~20GHz,
  却仍在 15.5GHz 上取方向图,读到的是带外辐射。
- 规则:远场指标只在**该变体自己的谐振点(或确认仍在带内)**上读。扫参时先看 S11 筛掉失谐变体,
  再对存活的变体取远场;或者每个变体在自己的 f₀ 上取。

## 两根 Γ 探针的水平耦合段是**竖直片**,高度 = 臂宽 `Fwa`:`Fh1 - Fh2 > Fwa` 是硬约束
- 现象:扫探针高度 `Fh1`,6.30mm 一切正常(P1 带 14.57–16.52),6.25mm **两个端口一起塌到 −8dB**。
  0.05mm 造成的悬崖,不是失配曲线该有的样子。
- 定位:`GetObjectBoundingBox` 一看就清楚——`Pr1_arm` 的 z 跨度是 `[Fh1-Fwa, Fh1]`(竖直片,不是水平片),
  `Pr2_arm` 是 `[Fh2-Fwa, Fh2]`。Fh1=6.30 时 Pr1_arm 底边 5.500 vs Pr2_arm 顶边 5.460,只剩 **0.04mm**;
  6.25 时 5.45 < 5.46 → **真的相交、两端口直接短接**。
- 判据:两端口指标**同时**塌 = 结构短接;只有一个塌 = 失配。前者别去调匹配,先量 bbox。
- ⚠️ 但 0.04mm 间隙**电气上不算耦合**:两臂是相互垂直的零厚度片,只在中心线边对边相邻,
  实测隔离度仍有 −35.5dB(Fh1=6.66 时 −45dB)。所以仿真结果可信——**问题在可加工性**:
  实物铜片有 0.2–0.3mm 厚,装上就碰。设计上要留 `Fh1 - Fh2 ≥ Fwa + 0.3mm`(原始 `Fdel = Fwa+0.4mm` 就是这么来的)。
- 要把 `Fh1` 继续压低,必须**连 `Fh2` 一起降**保住净空,再用 `Fd2` 把 P2 拉回带内。

## ⚠️ 修正:`Ghw/Hpo` 的带宽甜点**随探针工作点移动**,换了探针必须重扫
- 先前记的 0.846 是在旧探针配置下测的。把探针(`Fh1`/`Fry`/`Fd`)重新优化之后,甜点移到了 **0.80·Hpo**,
  而且这一个变量就把 P1 的 −15dB 带宽从 **1.95GHz 拉到 2.55GHz**(Ghw 5.922→5.6mm,Gb=9.7/Hpo=7)。
- 教训:在此之前我已经扫遍 `Fd`/`Fry`/`Fh1`/`Fwa`,得出"P1 带宽上限就是 2.0GHz、正好卡在需求上、没余量"的结论——
  **这个结论是错的**,错在没有回头在新工作点上重扫盒壁高。
- 规则:**探针参数大改之后,`Ghw` 必须重扫**。它不是"定好就不用管"的结构量,是和探针耦合强度联动的带宽旋钮。

## ★ 宽波束小型化版(100° HPBW / 0.44λ₀ / 双口 −15dB):最终配方
`Ku_CP_MEDipole.aedt` → design `wide_beam_v1`(2026-08-29)。f₀=15.5GHz,λ₀=19.34mm。
```
Gb   = 8.5mm  (0.439λ₀)      Hpo  = 7mm + 1.6*(9.7mm-Gb) = 8.92mm  (0.461λ₀)
Ghw  = 0.8*Hpo = 7.136mm     Lpl  = Gb/2-Sg/2-0.6mm = 3.165mm (0.164λ₀)
Sg   = 0.97mm                Wpo  = 1.93mm            Fw   = 1.1mm
Fwa  = 0.8mm                 Fgap = 0.3mm  (两臂净空)  zj   = 0.3mm
Fh1  = Hpo-0.7mm = 8.22mm    Fh2  = Fh1-Fwa-Fgap = 7.12mm
Fry  = 1.25mm  Fd  = 5.05mm  (P1)
Fry2 = 1.4mm   Fd2 = 4.4mm   (P2)
馈电:P1 ∠0° / P2 ∠+72°(结构固有偏置 +18°),等幅 → RHCP
```
实测:S11 两口 −15dB 覆盖 14.5–16.5(带内最差 −16.07dB);带内轴比 ≤0.62dB;
HPBW 100°(14.5GHz)→90°(16.5GHz),两主面差 ≤1.5°;增益 4.5–5.6dBic;旋向纯度 40.8dB。
- **`Hpo = 7mm + 1.6*(9.7mm-Gb)` 是等频率线**:缩 `Gb` 抬 `Hpo`,谐振点不动。缩尺寸/展波束就沿这条线走,
  沿线上 Gb 从 9.7 缩到 8.5,S11 不但没变差反而更好(−15.5→−16.1dB),HPBW 84.8°→99°,增益 7.0→5.1dBic。
  代价是**高度增加**(7.0→8.92mm)。footprint 受限就走这条线,高度也受限就得另找补偿量。
- Gb 再缩到 8.2mm 时 P1 掉到 −14.5dB(需重调),8.5mm 是不重新调谐的下限。

# 矩形微带贴片

## inset 馈电 = 在贴片上挖槽 + 馈线伸进去
- 现象:论文是 inset-fed,直接边馈建出来不匹配。
- 解法:在贴片靠馈电边 `subtract` 两条对称小槽(形成 notch),50Ω 微带馈线伸进 notch 到 inset 深度 y0。inset 越深阻抗越低:Rin(y0)≈Rin(0)·cos²(πy0/L)。y0 设成变量扫参调匹配。

## 匹配靠扫馈电位置,不是改贴片尺寸
- 现象:谐振频率对了但不匹配,想改 L/W 去凑。
- 原因:L 定谐振频率,馈电位置定阻抗匹配,两者解耦。
- 解法:先用 L 把谐振调到目标频率(L≈半波长/√εeff),再扫 inset 深度 / 探针位置 / 馈线参数把 S11 压下去。别用尺寸同时凑两个目标。

## 贴片有基模 + 高次模,别被"全局最低 S11"带歪
- 现象:`get_s_parameters` summary 报的 resonant_freq 是高次模(更深的那个 dip),还把两个 dip 之间算成一条超宽带(分数带宽几十 %)——其实中间 S11 回到 ~0dB。
- 原因:summary 取全局最小值,且简单地用首尾 -10dB 交叉点算带宽,不识别多谐振。
- 解法:复现单频贴片务必 `summary_only=false` 看完整 S11 曲线,自己认出工作频率附近的**基模** dip(通常不是最深的)。基模 ≈ 目标频率,高次模在 ~1.5× 处。(注:`get_s_parameters` 现已按连续 -10dB 段分组并给 `n_resonances`,多谐振不再被外包络掩盖,仍建议核对基模。)

## 库材料 εr 与论文不符时,谐振会系统性偏(FR4 尤其常见)
- 现象:照搬论文尺寸,谐振比目标低几个百分点。
- 原因:HFSS 内置 `FR4_epoxy` εr≈4.4,高于论文常用的 4.2/4.3;f∝1/√εr。
- 解法:用 `create_material` 按论文值精确建(见 `_general.md` 同类条,**首选**)。不便改材料时退而
  ① 接受偏移并在报告里讲清成因,或 ② 按 √(εr_lib/εr_paper) 比例缩贴片谐振长度 Lp / 扫参把 Lp 推到目标 f。
- 附带:FR4 损耗(tanδ≈0.02)会让增益比论文低 2-3dB、效率仅 ~40-50%,但方向图/HPBW/指向性仍对得上——
  用 FR4 复现时别把这个增益差当成建歪。

## 边馈贴片单独不会匹配 50Ω
- 现象:贴片边缘直接馈电,S11 只有 -2~-3dB,根本不匹配。
- 原因:贴片边缘输入阻抗 ~200-300Ω,远离 50Ω。
- 解法:用 inset 馈电(把馈线缩进贴片,深度调阻抗)、λ/4 阻抗变换段、或探针偏置到 50Ω 点。匹配靠把馈电位置设成变量后扫参找最优(`create_parametric_sweep` + `get_parametric_results`)。

# 四臂螺旋天线 QHA / PQHA(含印刷式、折叠臂、寄生臂多频)

适用:quadrifilar helix / 四臂螺旋 / 印刷四臂螺旋(PQHA)/ 分数匝谐振式 QHA。
心形宽波束 + 宽角圆极化,导航/卫通常用。本文件只记**类级别**经验,具体某款的毫米尺寸不入库。

## ⚠️⚠️ 已证伪:"顶端 U 形连通的主臂+寄生臂 = 双频"在仿真里不成立,之前的双频是建模伪影
- 实测对照(同一尺寸、同一 setup/材料/端口):
  | 连接段与主臂 | 模型 | S11 |
  |---|---|---|
  | 完全断开(间隙 ≥19μm) | 平面片拼(断点不对齐) | 单谐振 |
  | **完全连通**(create_helix 共边 unite 成一张片) | 真螺旋面 | **单谐振**(k=1: 2.116GHz,−10dB 2.048–2.216) |
  | **近乎断开,仅一点擦碰**(64 采样点中 1 点接触) | 平面片拼 | **双谐振 + 两谷间尖锐陷波**(2.052/2.228,陷波 2.156 ≈−0.4dB) |
- 结论:双频来自连接处**微米级缝隙的电容耦合**与寄生臂构成的 LC 陷波,不是 U 形连通结构本身的物理。
  所以之前"复现与论文吻合"含有巧合成分;凡是基于那版模型得出的结论(支撑 εr≈1.52 反推、长度比规律等)都要打折扣。
- 教训:**复现结果与论文吻合 ≠ 模型正确**。结构里有细缝/细线/弱接触时,必须用一个"保证连通"的建法交叉验证一次,
  若结果质变(谐振个数变化)说明原模型的吻合靠的是数值伪影。
- **受控耦合缝也无效(实测)**:在干净的真螺旋模型里,连接段完全连通(2.116GHz)、留 0.05mm 缝(2.124GHz)、
  完全断开(平面片 G/H)**都是单谐振且频率几乎一样**——寄生臂的连接状态对谐振影响 <0.5%。
  所以 F 那组双谐振不是可复现的电容耦合机理,判为点接触处的数值伪影,**别再沿"调耦合"方向尝试**。
- 要真做双频:换公认的双频 QHA 拓扑(阶梯宽度臂 stepped-width、长短两组臂、臂上陷波加载等),先查文献再建。
- 附:参数化螺旋改变量(如 k)后重建,Parasolid 会报 "Unable to transport profile to correct sweep start position",
  实测 bbox 仍正确;新建同尺寸模型无此警告且结论一致,判为无害,但改完变量务必 bbox 自检。

## ✅ 加宽的耦合寄生螺旋(顶端不连接)能产生第二谐振——但要避开与主臂谐振重合
- 结构:在主臂旁同一螺旋上加一条**独立开路**寄生带(不与主臂任何处连接),宽 wp、与主臂垂直间隙 gp、长 Lp,
  用 create_helix 参数化(圈数写成 Lp 表达式,底端锚定、只改圈数即可改长度)。
- 实测(k=1, wp=2.5, gp=0.5):Lp=65mm 时**仍单谐振**(寄生臂自谐振 ≈λg/2 恰与主臂谐振重合、合并成一个宽谷);
  Lp=55mm 时**出现第二谐振**:2.104GHz(−13.3dB) + **2.172GHz(−12.8dB,−10dB 仅 12MHz)**,中间 ~−7.8dB 驼峰。
- 含义:这是干净连通模型里第一次得到真实双谐振,机理是**两个谐振臂的耦合**,与原论文 0.1mm 寄生臂"顶端连通"无关
  (0.1mm 太弱,独立谐振出不来)。第二谐振对 Lp 非常敏感,且初始耦合偏弱(窄、浅)。
- 调参方向:gp 减小 → 耦合增强、第二带变宽变深;Lp 减小 → 第二谐振上移、两带间隔拉大;k → 两带整体平移。
- **⚠️ 但做不出大间隔(实测)**:Lp=50mm 时寄生谐振被推到 ~2.33GHz(与主谐振比 ~1.10),gp 从 0.3 收到 0.15mm(接近加工极限)
  **仍无第二谷**,只剩 −4dB 的小鼓包;S11 反而变成一个宽单谷(−10dB ~200MHz)。
  结论:**非直接馈电的耦合寄生臂只能在两谐振比 ≲1.03 时劈出(窄浅的)第二谷**,要 ~9.5% 以上的间隔耦合量不够。
  需要大间隔双频时改用**直接馈电**的结构:每臂根部分叉成长短两支(都接探针),或长短两套臂嵌套。
- **⚠️ 更正:上面全是单口 S11 口径,按有源反射(0/90/180/270°)重看结论不同(实测)**:
  - Lp=50, gp=0.15:ActiveS 是**单个深谷 2.088GHz −24.3dB**,−13dB 2.029–2.159(130MHz, 6.2%),−10dB 194MHz。
    单口判"失败"的这组,实际馈电下是很好的单宽带匹配。
  - Lp=55, gp=0.5(单口 S11 的"双谐振"组):ActiveS 谷只有 −13.3dB@2.084,**2.14GHz 处是 −2.5dB 陷波**,−13dB 仅 21MHz。
  - 含义:有源馈电下寄生臂的作用是**匹配元件 + 陷波器**,单口 S11 上的"第二谐振"其实是陷波把谷劈开;
    陷波离主谐振越远(Lp 短),主谷越深越宽。不要拿单口 S11 判断多口 QHA 的寄生结构成败。
  - Lp=52, gp=0.15, wp=2.5:谷 2.092 −22.4dB,−10dB 2.007–2.219(212MHz),陷波 2.236 在主谷上沿抬出 ~−12dB 平台(类第二极点)。
  - 同上但 wp=4:寄生谐振下移、陷波靠近到 2.216 且变浅,平台消失,主谷被推到 2.064,−13dB 带宽变窄。**加宽寄生臂不利于展宽**。
  - 求解代价:gp=0.15 的窄缝让网格很密,单次 19–27min(gp=0.5 时约 5min)——参扫前先想清楚方向。
- **主臂宽度参数化(建法)**:主臂轮廓只让上沿随 wm 变,`z_hi = 2mm-4.26722mm*k+1.42248*wm`(下沿不动 → φ=0 处下沿仍在 z=2mm,
  3.2mm 高的探针照样接上);寄生臂起点跟着主臂上沿走 `z_lo = 2mm+1.42248*wm+4.04624mm*k+1.42248*gp`(wm=2.5 退化为原模型)。
  改 wm 后 bbox 自检:PAR2 的 zmin/zmax 应同步移动 1.42248·Δwm。validate 0 warning(实测)。
- **主臂宽度 wm 对有源匹配影响很大且非单调(实测 Lp=52, gp=0.15, wp=2.5, k=1)**:
  - wm=2.5:单谷 2.092 −22.4dB + 上沿 −12dB 平台。
  - wm=4:**两个极点** 2.120(−16.2) + 2.224(−15.2),中间凸起 −11.9dB,−10dB 2.037–2.233(196MHz)——平台变成真第二极点,主谷整体上移。
  - wm=4.75:宽单谷 2.112 −18.9dB,−10dB 2.013–2.241(229MHz,上下沿比 0.90),2.20–2.225 有 −12.2dB 平台;−13dB 2.047–2.191。
  - wm=5.5:**主谐振消失**,低频 ActiveS 只有 −1.4~−3dB,仅剩 2.232 单谷。主臂过宽后主模失配(探针接在宽臂下沿)。
  - 含义:加宽主臂能把寄生臂陷波旁的平台"拉"成第二极点,但有明确上限;在 4 附近细扫,别大步跳。
- **✅ 支撑介质改空心是展宽带宽最有效的一步(实测 wm=4.75, Lp=52, gp=0.15, wp=2.5, k=1)**:
  实心支撑 εr≈1.52 → 空心(只留 0.254mm Duroid 管),ActiveS 谐振 2.112→2.308GHz(上移 9%),
  −10dB 229MHz→**320MHz(13.7%)**,−13dB 144MHz→**273MHz(2.221–2.494)**,并出现第二极点 ~2.484(−16.8dB),中间凸起 ~−13.4dB。
  调了 wm/Lp/gp 一整轮都卡在 −13dB 上下沿比 0.93,换空心后一步到 0.893。**展宽 QHA 带宽先降支撑介质的有效 εr,再调臂宽**。
- **按比例缩放到目标频段的做法**:用 k=1 的有源反射曲线,扫一个频率缩放系数,算两个目标带里的最差值,
  取"两带都 ≤ 门限"的系数窗口的中点(本例窗口 1.1216–1.1334,取 1.1275)。建最终模型时 wm/gp/wp/Lp/gndR 都写成 `×k`,
  管壁厚和 SMA 探针不缩放(会带来小的频偏,需求解验证);端口是字面坐标,要新建 design 放在 16mm×k。
  - 实测缩放非理想:预测 −13dB 上下沿比 0.893,k=1.1275 实际 0.904(下沿比预测高 1.2%,上沿低 0.3%)。留足窗口余量,或缩放后再修。
  - 小幅改 k(<±4%)不必新建 design:探针偏离臂面 < 探针半径 0.635mm 仍接触。
- **收尾微调时寄生臂长度 Lp 极敏感(实测 k=1.137 空心)**:Lp 52→51 mm×k,第二极点上移 ~2.3%,两极点间凸起 −16.3→−12.0dB。
  上沿不够时只动 0.5mm 级,别一次 1mm。
  - 收敛结果(1.98–2.01 / 2.17–2.20 GHz,ActiveS ≤−13dB):k=1.137, wm=4.75×k, gp=0.15×k, wp=2.5×k, **Lp=51.5×k**, 空心支撑,
    −13dB 连续 1.972–2.206(凸起最高 −13.9dB),两带最差 −13.75/−13.92dB;2.09GHz θ=80° LHCP +0.53~+0.65 dBi。
- **⚠️ 双谐振 ≠ 好方向图:决定波束形状的是辐射体口径,不是"在不在自己的谐振上"(实测判定)**
  分叉臂(根部分叉、两支都直接馈电)能给出两个独立谐振+中间陷波,正是文献里的双频形态;但在**短支自身谐振**处取远场,
  波束仍是锥形:θ0 −1.74dBi、峰值 +1.2~+1.6@56–58°(2.17GHz),2.20GHz θ0 −4.4dBi。
  原因:所谓"短支"只是**起点抬高**(z 6.9→75.9 vs 主臂 2→76.2),轴向口径与主臂几乎一样,长度只差 ~7%——双谐振靠的就是这点差异。
  **口径相同 → 方向图相同**。要让高频带回到宽波束,辐射体必须物理上更矮(不同半径/高度的嵌套双圆柱),而不是同一圆柱上换一支臂。
- **分叉臂的短支谐振深度由缝内介质决定,与带宽互斥(实测三点)**:同一几何(k=1.142, gb=0.5×k),
  εr=1.52 → 短支 −14.8dB;εr=1.2 → 仅 −8dB(陷波 2.138 + 谷 2.158);空心 → **短支谐振完全消失**(1.85–2.35 内无第二极点)。
  而空心才是展宽主谐振的手段(−10dB 143→181MHz、主谷 −12.7→−14.4)。喂饱短支的介质同时压窄带宽,两个目标互相打架。
- **⚠️ 靠寄生臂第二极点撑出来的高频带,方向图轴向凹陷(实测)**:上面收敛设计的 LHCP realized θ=0:
  1.98 +3.0 → 2.09 +1.1 → 2.17 −1.6 → 2.20 −2.3 dBi,峰值偏到 θ≈52–56°(锥形);匹配达标≠远场达标,**宽带匹配后必须在带边算远场**。
- **降轴向高度/加大半径治不了这个凹陷(实测证伪)**:R 18.2→20.6、高度 −15%(螺旋角 45°→37°):1.98 轴向 +4.9 但 θ=80° 掉到 −1.45;
  2.20 轴向仍 −2.14(几乎不变),2.09→2.20 轴向骤降 6dB。高宽比只在"轴向↔宽角"间搬增益。
- **凹陷也不是寄生臂第二极点造成的(实测证伪)**:同一设计把 Lp 缩短到极点移出带外,2.20 轴向 −1.93(有极点时 −2.34),轴向随频率走势不变。
  → 是**主模式本身**:频率高于主谐振约 7% 后方向图变锥形。单个 QHA 主模式在"轴向与 θ=80° 都 > −1 dBi"判据下,
  方向图带宽 < 10.5%;匹配能靠寄生极点展宽,方向图不能。**两频相隔 ≳10% 且都要宽波束时,需要两个各自谐振在带内的辐射体**。
- **同圆柱交错 8 臂(长短两套 QHA)建法(validate 0 warning)**:两套臂同 Rh/P,短臂轮廓放在 φ=−15.106°+45°=29.894°
  `(Rh·0.866936, Rh·0.498432, 2mm−0.0419611·P)`,z 基准与长臂相同 → 在 φ=45° 处下沿正好 z=2mm,探针照样接上。
  圈数分别 `(Htl−2mm)/P+0.049`、`(Hts−2mm)/P+0.049`,各自按 Htl/Hts split 顶端(split 一次只选同一套臂)。
  相邻臂在 z 向错开 P/8,垂直净间距 = P/8/F − 臂宽。8 个同轴口(L 在 0/90/180/270°,S 在 45/135/225/315°,半径 Rh·0.707107 分量)。
- **两套臂用各自的螺距(短臂 Ps 独立于长臂 P)**:短臂所有公式换成 Ps 即可——轮廓 z 基准 `2mm−0.0419611*Ps`、
  线宽系数 `sqrt(1+(Ps/(2*pi*Rh))^2)`、圈数 `(Hts−2mm)/Ps+0.049`,仍在 φ=29.894° 起扫,φ=45° 处下沿正好 z=2mm 接探针。
  **注意 create_helix 的 pitch 写进历史,事后改不了共享变量**——想让两套臂分别用 P/Ps,必须新建 design 重搭。
  用途:保持短臂弧长(谐振不变)同时降低高度、压小螺旋角 → 展宽波束补 θ=80° 增益。
  例:Rh=18.192,臂长 95.6mm;P=115.62→Hts=70(螺旋角 45°) vs Ps=80→Hts=56.8(35°)。
- **⚠️ 但同一圆柱面上两套臂不能用不同螺距(实测证伪 + 几何证明)**:螺距小的那套爬升慢,沿 φ 逐渐掉到相邻大螺距臂下面,
  净间距 = (起始 z 差) − (P−Ps)/360·φ,线性收敛到 0 后两片相交 → 两套臂短接,ActiveS 全频段 −6~−0.7dB 无谐振、增益塌掉。
  实例:Rh=18.192、P=115.62、Ps=80,交叉在 φ≈155°,而短臂需扫 247°;保 2mm 间距只能扫 90°。
  **判据**:必须 (P−Ps)/360 × (短臂 φ 跨度) < 起始 z 差 − 臂宽 − 余量。差一点点都不行时,唯一出路是把两套臂放到不同半径(嵌套双圆柱)。
- **交错 8 臂的相邻臂耦合很强(实测 Rh=18.19, P=115.6, 臂宽 5.4, 净距 4.8mm)**:S1→L1 −7.8dB、S1→L2 −9.1dB(2.2GHz),对面 −30dB。
  "双工器"口径(带外那组 50Ω 端接)下约 29% 功率被吸收 + 失配,带2 realized gain 掉 ~2.5dB(θ80 −4.3dBi)。
  相位本身没问题(只激励短臂 θ0 RHCP −36dBi)。先诊断:读 dB(S(L1,S1)) 等耦合项 + RHCP,别直接调尺寸。
  对策方向:窄臂拉大净距(各带只需窄带宽时可行)。另注意 50Ω 端接是悲观口径,真实双工器带外呈电抗性。
- **窄臂的效果(实测 臂宽 5.4→2.5, 净距 4.8→7.7mm)**:耦合只从 −7.8 改善到 −8.9dB;但长臂带匹配/远场全部达标
  (谷 −19.9dB,1.98GHz θ≤80 最差 −0.39),短臂 2.20 轴向从 −2.93 升到 −0.18;短臂 θ=80° 仍 −3dBi(波束偏窄 + 端接吸收)。
  → 交错同径排布下,耦合主要由臂间距/螺距决定,调臂宽空间有限。
- **圆柱面上的水平弧形带:用 create_helix + 极小螺距(实测可行)**:竖直短线轮廓放在起始方位角,`pitch='0.01mm'`,
  `turns=Δφ/360`,扫出来就是贴圆柱面的水平弧带(51° 弧 z 只升 0.0014mm)。bbox 与解析值一致,validate 0 warning。
  用途:共馈结构里把短臂底端并到相邻长臂馈点(与两臂底端面-面重叠,不 unite)。
- **共馈(短臂经底部弧带并到长臂馈点)的有源反射行为(实测 Rh=18.19, P=115.6, 臂宽 2.5, 连接带 51°×2.5mm)**:
  - 带1(长臂)非常好:Hts=60 时谷 1.986 −38.7dB,−13dB 1.908–2.062;1.98/2.01 θ≤80° LHCP 最差 −0.04/+0.11 dBi(与 8 口双工器口径比,没有端接吸收损失)。
  - 短臂支路表现为**陷波 + 紧贴其上方的浅谐振**,和早期"根部分叉臂"同一机理:Hts=70 陷波 2.07(−3.2dB)、其上 2.15 小谷 −8.3dB;
    Hts=60 陷波推到 2.29(近全反射 −0.9dB),谐振出了扫频范围。**Hts 灵敏度远超"电长度∝1/f"估算**(−10mm 轴向 → 陷波 +10.6%)。
  - 教训:连接带会把短臂电长度加长,且支路整体是并联谐振器;估算 Hts 修正量时别用线性长度法,先小步(~1mm)定位。
  - 8 口交错排布里求解 ~20–28min;共馈 4 口 Hts=70 时 6min,Hts=60 时 46min(同样 12 passes,网格收敛难度随谐振位置变)。
  - **Hts 全扫(60/62/64/66/68.8/70)判共馈失败**:带1 处处 −18~−26.5dB 很好;短臂支路始终只是"陷波 + 上方 ~0.1GHz 的浅谐振(−8~−11dB)",
    陷波随 Hts 增大单调下移(2.282→2.042),**带2 最好只有 −8.2dB**。共馈并联支路给的是极点-零点对,靠支路长度调不出深谐振;
    要深的第二带,支路必须能独立匹配(独立端口/独立馈电网络),或改成两套不同半径的嵌套 QHA。

## ⚠️ 共边的螺旋带 unite 不可靠(3 次里失败 2 次)——改用"重叠 + 不合并"
- 现象:三条沿同一螺旋扫出的带(主臂 / 连接带 / 分叉支),按"下沿=上沿"设计成共边,`unite` 报 ok,
  但对象全部消失、`validate` 报 `Null body found`,整个 design 报废。把连接带起点挪开避免三面共点也照样失败;
  之前一次同类 unite 成功过,属于侥幸。
- 原因(推断):"共边"其实只到亚微米级相等——表达式常数取 5 位小数(如轮廓 z 偏移 4.26722 vs 精确 4.26682,差 0.4μm),
  Parasolid 对"几乎接触但没接触"的边做布尔很容易出退化体。
- 解法:**不 unite**。连接带向两侧各**重叠 0.2mm**进主臂和分叉支(面-面重叠而非边-边相接),三块各自赋 PE。
  重叠量远大于常数取整误差,接触有保证;也彻底绕开会删对象的布尔操作。(待实测验证后更新此条)

## ✅ 大间隔双频的可行结构:根部分叉、两支都直接馈电(实测)
- 结构:每臂 = 长支(主臂,定 f1)+ 短支(沿同一螺旋、在主臂 +z 侧偏移 gb、宽 wb、长 Lb,从 u=0 起)
  + 根部连接带(u≈0.3–2.4mm,**向两侧各重叠 0.2mm**,三块各自赋 PE、不 unite)。validate 0 warning。
- 实测(k=1, Lb=78, gb=1, wb=2.5):**两个独立谐振 2.112GHz(−17.2dB, −10dB 184MHz) + 2.332GHz(−13.4dB, 16MHz),
  频率比 1.104**——耦合寄生臂最多只做到 1.03,直接馈电一步到位。
- 仍需调:短支谐振又窄又浅,且紧贴一个近全反射陷波(2.316GHz),说明两支互作用强;短支顶端会逼近/超出基板顶。
- **加宽短支适得其反(实测)**:wb 2.5→4mm,短支谐振 −13.4dB/18.6MHz → −11.1dB/4MHz(更窄更浅),
  主谐振还被拉低 16MHz(2.112→2.096)。
- **拉开支间距也适得其反(实测,更正上面的推断)**:gb 1→2mm,短支谐振 −13.4dB → −8.4dB(连 −10dB 都不到),
  陷波仍在。说明**两支耦合是在帮短支谐振匹配**,不是干扰。
- **支间距 gb 有明确最优点(实测扫描 Lb=78, wb=2.5, k=1)**:gb=0.5 两谐振合并成宽单谷(−10dB 2.040–2.256);
  gb=1 两个独立谐振(短支 −13.4dB,最好);gb=2 短支只剩 −8.4dB。**但在最优 gb 处短支谐振也只有 ~−13dB**,
  单靠 gb/wb 做不到 −15dB——要再加自由度(Lb、分叉位置)或换评估口径(有源反射)。
- 端口是字面坐标,**已建模型里改 k 会让探针脱离臂**(k>≈1.04 就碰不到),最终缩放要新建 design。

## 多口顺序馈电的 QHA:按有源反射 ActiveS 判匹配,别只看单口 S11(实测差异明显)
- 做法:`set_port_excitation` 设 0/90/180/270°,`get_s_parameters(expression='dB(ActiveS(P1:1))')`(需显式传 setup/sweep/port)。
  改的是后处理权重,不用重新求解。
- 实测(分叉臂 Lb=78, gb=1, wb=2.5, k=1):单口 S11 谐振 2.112(−17.2)/2.332(−13.4);**有源 2.084(−16.1)/2.324(−14.8)**——
  两谐振都下移(低频移 28MHz)、高频谐振加深 1.4dB,频率比 1.104→1.115。按单口调出来的尺寸在实际馈电下会偏。
- 相位顺序决定旋向,也决定"哪个模式的匹配":先用远场确认——该模型 0/90/180/270° 下 θ=0 LHCP +2.4dBi、RHCP −48dB,即左旋。

## ★ 推荐建法:create_helix 扫真螺旋面(已实测几何正确)
- 结构拆解:主臂、缝、寄生臂在**同一 u(周向位置)上只是 z 方向的偏移**——
  主臂带 [0, wz_m],缝 [wz_m, wz_m+g_z],寄生臂 [wz_m+g_z, wz_m+g_z+wz_p](各宽度 = 垂直宽度 / u_dir)。
  所以三者都是"竖直短线沿同一螺旋(同半径、同螺距)扫出来的带",边界螺旋线天然重合。
- 三条带:MAIN(主臂带,覆盖全长并两端外延)、PAR(寄生臂带,只覆盖寄生臂的 u 范围)、
  CONN(缝那一段,从寄生臂顶端下方 ~1mm 起到顶,充当 U 形转折)。各自 `create_helix` 一次,
  MAIN 用 `split` 在 z_底 保留上侧、z_顶 保留下侧,CONN 在 z_顶 保留下侧,最后 `unite` 三条带 → 一张连通的片。
- 参数全部写成缩放变量 `k` 的线性表达式(半径、螺距、轮廓坐标、z 偏移、管/支撑高度随 k;线宽/缝/板厚/探针高度不随 k),
  可直接 `create_parametric_sweep` 扫 k 调频率。螺距 = slope·2πr0,圈数与 k 无关。
- 实测验证(k=1.0256):bbox 与预计算逐项吻合到 0.001mm;`right_hand=True` 对应 φ 随 z 增大;unite 后单一 sheet。
- 旧的"共面梯形平面片拼"方法见下,仅在没有 create_helix 工具时作为兜底。

## 工具没有 sweep-along-path,螺旋带用"共面梯形分段"建
- 现象:`create_polyline` 只能覆平面;把整条螺旋带的边界点(50+ 个点在圆柱面上)一次闭合覆面必然失败——
  柱面上的闭合折线不共面,CoverLines 覆不出来。也没有扫掠/螺旋图元可用。
- 原因:螺旋带是柱面上的曲面片,任何跨越 Δφ 的四点一般不共面。
- 解法:**按"两条同 φ 的竖直线段"分段**。每段取 φᵢ 和 φᵢ₊₁ 两个角度,各画一条**竖直**线段(z 从带下沿到上沿),
  四个端点 = 两条平行竖直线的端点 → **必共面**,覆面 100% 成功。16 段覆盖 200° 足够(弦弧误差 <0.1%)。
  建完 `unite` 成一条臂 → `assign_perfect_e` → `duplicate_around_axis(90deg, n_clones=4)` 出四臂。
- 配套换算:带宽是**垂直于带走向**量的(论文给的就是这个),分段时需要的是**沿 z 量的带宽**:
  `带宽_z = 带宽_⊥ / u_dir`,其中 `u_dir = 周向弧长 / 臂长`(臂方向的周向方向余弦)。
  两条并行臂(主臂+寄生臂)的中心距同样要除以 `u_dir` 换算到 z。这样建出来的**垂直间隙**才等于论文值——
  建完拿这个反算一遍间隙当自检,能立刻发现方向余弦用反了。
- 偏移方向别搞反:垂直于带方向有两个,选错会让寄生臂跑到主臂另一侧(间隙仍对但拓扑镜像了)。
  判据:算出来的寄生臂应当在**主臂的 +z 侧还是 −z 侧**,和展开图对一下。

## ⚠️ 端头要切成**完整**水平面,轮廓起点必须往回退够、扫掠圈数必须够长(2026-09-16 用户发现的建模缺陷)
- 螺旋带垂直宽度 w、螺距 P、半径 R,则 z 向宽度 `Fz·w`,其中 `Fz = sqrt(1+(P/(2πR))^2)`;每度上升 `P/360`。
- **底端**:轮廓要放在目标起始方位**之前** `Δφ = Fz·w/(P/360)` 度,且轮廓 `z_lo = z0 − Fz·w`(起点处整条带子都在切割面 z0 以下)。
  这样 z0 平面切出的是一条完整水平边,arm 从一个点渐宽到满宽,**没有竖直端面**。
- **顶端**:扫掠圈数要满足 `turns ≥ (z_top − z_lo_start)/P`,否则带子下沿还没越过切割面,sweep 就结束了,
  `split` 只削掉斜出去的上半边,留下高度 `z_top − z_lo_end` 的**竖直端面**(直角)。留 0.02 圈余量,多扫的会被切掉。
- **踩坑实例**:原文复现是 w=2.5mm(Fz·w=3.556)配 Δφ=15.106°、0.688136 圈,刚好够;
  后来把臂加宽到 w=4.75mm×k(Fz·w=7.68)却**没改 Δφ 和圈数**,结果两端各留 2.83mm 竖直面。
  内圈臂更糟:轮廓直接画在馈电方位、z 从 2 起(Δφ=0),底端是整整 7.0mm 的竖直面。
- **自检**:`Δφ·(P/360) ≥ Fz·w` 且 `turns·P ≥ z_top − z_lo_start`;bbox 看不出这个缺陷,要么算,要么在 3D 窗口看端头。
- **悬空的寄生带也要切成水平端头(用户要求,2026-09-18)**:保持中心线长度 Lp 不变——轮廓起点往回退 Δ(本例 8°,需 > z向半宽/(P/360)),
  z 同步下移 `P·Δ/360`,圈数加 `2Δ/360`;底端切在原起点的**中心线高度** `z0 + Fz·wp/2`,顶端切在其上 `Lp·P/弧长每圈`(本例 `0.711127·Lp`)。
  两端各切掉一个三角、补回一个三角,电长度基本不变。
- **⚠️ 0.17mm 级窄缝的寄生耦合对网格极敏感**:k 只差 0.16% 的三次求解,寄生极点在 2.186(−30dB)/2.194(−20dB)/~2.206(−12.8dB) 间跳动,
  不单调。此时靠微调 k 找"两带都过线"的点没有意义——余量小于仿真重复性。

## 螺旋臂的端头是"水平切平"的,不是垂直于带走向、更不是竖直切
- 现象:用共面梯形分段法建螺旋,每段的边都是 φ=常数的**竖直**线,于是臂的最顶端天然成了一条竖直切边。
  对着侧视图一看就错了——真实的带子是**齐着筒口被水平面切平**的,展开图顶端也是一条水平横边。
- 后果远不止端头形状:**它让整体轴向高度算错**。带宽沿 z 有 3~4mm,若让"中心线"的轴向跨度等于论文的 H,
  带边缘就会超出 H,整根天线高出一截(实测高了 3.79mm / 5.8%),匝数也跟着偏小。
- 判据:论文图上那个轴向高度箭头,通常是从地板量到**筒口**,即"整体高"(带边缘到带边缘),
  不是螺旋中心线的跨度。据此列方程:`H = 中心线轴向跨度 + 带宽沿z`,而带宽沿 z 又依赖方向余弦,
  **要迭代解**(几轮就收敛)。解完再验:臂长仍应等于论文给的那个长度。
- 建法:让带的两端**向外多延伸一截**,再把所有顶点的 z **钳制**到 [z_底, z_顶]。
  分段法每段 4 点落在两条竖直线上,只改 z 不破坏共面性,端头自然变成水平边。
  (不要试图用 box 去 subtract,sheet 减不了 solid——见 `_general.md`。)

## 与螺旋臂 T 形相交或大面积重叠的 sheet,不能 unite 进臂里
- 现象:把顶端的**水平径向段**和螺旋臂一起 `unite`,`assign_perfect_e` 还能成功,
  但下一步 `duplicate_around_axis` 报 `com_error 发生意外`,**并且回滚时把 unite 出来的对象一起删掉了**——
  `list_objects` 里臂凭空消失。
- 原因:水平片与斜螺旋片成 T 形相交(不是共边拼接),unite 出的复合 sheet 拓扑退化,旋转复制处理不了。
- 同类坑:顶端把主臂和寄生臂连起来的那块"U 形转折",若做成**覆盖两条带本身**的大块(与它们重叠),
  `unite` 会直接报 ok 却把整条臂弄没。正确做法是让它**只填两条带之间的缝隙**
  (主臂上沿↔寄生臂下沿),与两条带只**共边**、不重叠。
- 解法:**径向段单独建、单独赋 PE、单独 duplicate**,不要并进臂。两个独立 PE sheet 相交处电流照样导通,
  电气上等价。判据:凡是与主体**成角度相交或面积重叠**(而非共边续接)的片,都单独留着。
- 分组 unite 更稳:主臂一组、寄生臂一组、连接块一组,三个对象一起赋 PE、一起 duplicate
  (`duplicate_around_axis` 的 objects 接受列表)。一组失败不会把另外两组一起赔进去。
- 让相交是"面-面"而不是"点-点":水平径向段若正好止于臂所在柱面,只和臂的竖直边**交于一点**,电流传不过去。
  让径向段从 `r > r_arm` 起(多伸 0.5mm 穿过柱面),两平面相交成一条**线段**才算真搭上。

## 分数匝 QHA 的匝数由"臂长/轴向高度/半径"三者中任两个锁死
- 机理:臂沿螺旋展开是直角三角形——`臂长² = 轴向高度² + (2π·r₀·N)²`。
  所以论文只要给了臂长、轴向高度、半径,**匝数 N 就没有自由度了**,反之给了 N 就少给一个。
- 用途:论文常常不直接写 N(本类文献很常见)。拿这个三角关系反解即可,**不要去图上数圈数**。
- 陷阱:若论文的设计公式里有 `(L₀ − A·r₀)` 这类修正项(A=1 开路 / A=2 短路),
  那 L₀ **含一段不参与螺旋的端部导体**,反解 N 时必须先扣掉,否则 N 会算大一倍。
  两种解都要算,再拿"代回公式能否复现论文标注的轴向高度"当判据——能精确复现的那个才是作者的本意。
- 但**几何自洽 ≠ 图上存在**:扣掉的那段端部导体如果在结构图上根本画不出来(顶端干干净净),
  说明它可能只是经验修正项而非实体。**两个解都建出来跑,用谐振频率和方向图裁决**,比纸上推理可靠。

## 顶端径向段指向轴心时,4 条会在中心撞车
- 现象:A=1 时每臂顶端一段长 r₀ 的径向短截线,4 条都指向轴心 → 在 r=0 附近互相重叠,等于把四臂短路在一起。
- 解法:径向段**止于 r_min**,由带宽定:`r_min ≥ (带宽/2)/sin(45°)`(相邻臂夹角 90°)。
  带宽 2.5mm 时 r_min ≈ 1.8mm,取 2mm 安全。这会让臂总长比论文短一点,**必须在报告里记这笔账**。
  想保长度就让径向段**向外**折——4 条互不干涉,但天线横向尺寸翻倍、方向图会变,通常不可取。

## (存疑)主臂 + 顶端折回的寄生臂 = 双频;长度比≈频率反比
- ⚠️ 见文件顶部:完全连通时仿真是单频,下面的"机理"来自含接触伪影的模型,仅作历史记录。
- 原记:寄生臂在顶端与主臂相连、另一端开路,构成第二条谐振路径(频谱上表现为两个匹配谷之间夹一个
  近乎全反射的陷波点)。主臂/寄生臂长度比 ≈ f_高/f_低(复现实测吻合到 1%),可用来验论文尺寸自洽性。
- 调频率优先**整体等比缩放**:每个带的 −10dB/−15dB 带宽往往宽于目标,两带同比例移动存在可行缩放区间
  `k ∈ [max(f_目标高边/f_实测高边), min(f_目标低边/f_实测低边)]`,非空就等比缩放半径、高度、两臂长(工艺量不动)。
- (曾记"改长度比会让两谐振合并"——**已证伪**,那次失败的真因是下一条的接触问题,不是物理。)

## ⚠️ 分段拼螺旋时,相邻部件必须共享断点,否则寄生臂会悬空
- 现象:同一套生成器、只改尺寸(甚至纯等比缩放),**第二谐振直接消失**,只剩一个跟主臂长度走的谐振;
  求解反而更快;消息窗口出现 `Minor Mesh Repair (TAU) on body "寄生臂"`。换建模顺序、换网格设置、换支撑
  材料写法全都无效,几何/对象/边界清单也和好的设计一模一样。
- 根因:主臂、寄生臂、顶端连接段各用**不同的角度断点网格**分段。每块平面片是圆柱的弦,中点向内凹
  `r(1−cos(Δφ/2))`(r=16mm、每段 ~11° 时约 0.077mm)。断点不对齐时,连接段的边离主臂的面片
  **差几十微米、根本没接触** → 寄生臂整条悬空 → 陷波和第二谐振一起消失。
  实测:好用的那版只有 1/64 个采样点碰巧接触(纯运气);改尺寸后两版都是 0/64(最小间隙 19~43μm)。
- 判据:**别只看 bbox**,要算相邻部件边到面片的最小三维距离;"只剩一个谐振且求解变快"就先怀疑这个。
- 解法:(1) 所有相邻部件在接触区用**同一套断点**,共享顶点;
  (2) 更好的是用 HFSS 原生 `CreateHelix`/扫掠建真正的螺旋面,主臂+缝+寄生臂做成**同一张片再挖缝**,
  天然连通且可参数化——有这个工具就别再用平面片拼。

## 四端口 QHA 的馈电与极化
- 四臂等幅、相邻 90° 递进,用 `set_port_excitation` 设 0/90/180/270。它改的是**后处理叠加权重**,
  改完直接取远场,**不用重新 analyze**。
- 旋向 × 相位递进方向共同决定 LHCP/RHCP。拿 `get_radiation_pattern(polarization='lhcp')` 一看即知:
  主瓣朝上且增益为正就是对的;反了就把相位序反过来(0/270/180/90),不必改几何。
- 同轴探针接在臂根部:臂底端若正好落在地板平面,探针长度为 0 建不出来。把臂整体抬高一个 `hf`(2mm 量级)
  让探针从地板穿上来,`z_top` 取**臂根部那一段的 z 中点**,探针侧面才能和臂的斜面切实相交(不是蹭到一个角)。
- 探针必然与卷曲基板圆筒相交,HFSS 直接报 `Parts tube and pin intersect` error。
  `subtract(blank=筒, tools=[各探针], keep_originals=True)` 在筒上开孔即可——物理上正是 SMA 穿板。

## 地板直径对 QHA 的增益/HPBW 影响有限,且很快饱和
- 实测:地板直径从 1.0λ 扩到 1.64λ,峰值增益只涨 0.25 dB(3.47→3.72,且 1.3λ 处就到顶、再扩反降),
  HPBW 只收窄 7°(157°→150°)。
- 含义:**地板是微调量,不是主控量**。若实测 HPBW 比目标宽十几度、增益差半个 dB 以上,
  扩地板换不来,别在这上面烧求解时间——去查匝数、轴向长径比、介质加载。
- 地板直径在论文里常是 unknown(图上画了但不标)。起手取 1λ 直径即可,它不影响谐振频率。

## 波束"峰值偏轴"是形状问题,一个原因同时压低增益并展宽 HPBW
- 现象:增益比论文低 ~0.7 dB,同时 HPBW 比论文宽 ~17°,看着像两个独立缺陷。
- 实质:对着论文的增益-角度曲线比形状就清楚了——论文是**轴上最强的平顶心形**,
  自己的是**峰值偏轴几十度的锥形**。能量往外挪,轴上自然低、3dB 点自然被推远。**是一个病,不是两个。**
- 排查顺序:先比**形状**(峰值在不在 θ=0),再谈数值差。形状不对就别去调地板这种微调量。
- QHA 的波束形状主控量是匝数 N 和轴向长度/直径比;介质加载也会改形状(见下条)。

## 用实心介质柱等效真实支架:频率能凑准,方向图未必等效
- 背景:论文常只说"缠绕在圆柱形支架上"而**不给支架材料**。把筒内填实、反推等效 εr,
  可以把谐振频率调到和论文一致(实测两个频点独立外推出的 εr 一致到 1.3%,验证点一次命中到 0.2%)。
- 局限:**频率对上 ≠ 结构等效**。实心柱和薄壁管即使等效 εeff 相同,近场分布和轴向辐射也不同,
  方向图/增益/HPBW 仍可能对不上。
- 纪律:反推出来的 εr 要**单独标注为推断值**,不能和"复现一致"的指标混在一起报;
  残留的方向图偏差要优先怀疑这个等效,而不是继续调别的参数去凑。

## 对标远场指标前,先看清论文图的纵轴标的是哪个量
- 现象:论文图纵轴写 `Gain Total (dBi)`,而顺手取的是 LHCP 分量增益,两者不是一回事。
- 但注意:**CP 纯度很高时两者几乎相等**(实测 AR=0.077 dB 时,total 3.40 vs LHCP 3.38,差 0.02 dB)。
  所以这个差异能解释的量级很小,别指望靠换极化分量补上零点几 dB 的缺口。
- 做法:对标前把纵轴标签、gain 类型(realized 含失配 / total)、切面 phi 都和论文对齐再比数。

# 参数优化经验(不限天线类型)

做参数扫描/匹配/方向图优化时反复踩到的坑与方法论。开工要扫参/调匹配/优化方向图时先读这篇。

## 参扫的三个坑代码都已兜底,看返回字段即可(别退回手动 workaround)
- **表达式型变量**(如 `0.1*109.1mm`、`MH1-0.01*lambda`)直接扫会 `InsertSetup(OptiParametric)` com_error。
  `create_parametric_sweep` 建参扫前已自动把被扫变量钉成求值后的纯数值(单位保留),返回里 `pinned_to_numeric`
  列出被改的变量 —— **不用再手动 `set_variable`**。只有返回里没 `pinned_to_numeric` 又仍 com_error 才手动钉。
- **某组合求解失败**不再让整份报告作废:所有 `get_parametric_*` 逐组容错,跳过失败组照常返回成功组,
  失败组进 `failed_variations`(`results` 里带 `error`)。仍建议**扫前估极值**(对范围两端 `set_variable`
  → `get_object_bbox` 看越界/穿插)减少无谓失败组;失败组多到关键区间都没解时,再手动逐点 `set_variable`→`analyze`→`get_*`。
- **-10dB 带宽看 `n_resonances`,别看外包络**:`get_parametric_results` 每组直接给 `n_resonances` 和(>1 时)
  逐段 `resonances`,`bw_-10dB_low/high` 只覆盖**基模那一段**。`n_resonances==1` 才是真连续宽带;>1 说明中间有洞。
  无需为此逐组重跑 `get_s_parameters`。

## 同会话内可秒回复用参扫的解
- 现象:逐点读数时每次 `analyze` 都怕全程重算(~150–180s)。
- 解法:**同一会话**里,跑完参扫后把 nominal 变量设成某组合的值再 `analyze`,HFSS 复用该组合的解(秒回 ~4s),即可用稳定的 `get_s_parameters`/`get_radiation_pattern` 逐点读。注意:存盘/关闭/重开**之后复用失效**,每点变回全程重算。

## 改完变量记得还原并重算锁定配置
- 现象:为做对比临时翻动变量(如把 HP 调回原值测高频),Setup 的 nominal 解随之失效,留下脏状态。
- 解法:测试完把变量改回锁定值,并重 `analyze` 一次,确保保存的工程是锁定配置的有效解。

## 取非自适应频率的方向图要新建该频 setup
- 现象:`get_radiation_pattern` 只对 `LastAdaptive` 稳;想看带边频点(如 3GHz)的方向图,对离散扫频取会报 com_error。
- 解法:`create_setup` 新建一个该频率的自适应 setup,`analyze` 后用它的 LastAdaptive 取图(Sphere1 + 辐射边界沿用即可)。
- 更新(2026-10-23,2025.2 实测):扫频建成 `sweep_type='Discrete', save_fields=True` 时,对离散扫频取远场是正常的
  (6 个频点一次取出,和自适应频点的结果连续)。报 com_error 多半是那条扫频没存场。
  多个频点时工具按 `by_freq` 返回(之前的版本只解析第一个频点,其余的会被静默丢掉),也可以传 `freq` 只取一个。
  新建单频 setup 的做法仍然可用,但要多做一次自适应。

## 优化方法论(判断陷阱)
- **双谐振宽带匹配**:耦合强(馈线离壁间隙小)→两谐振合并成连续宽带;耦合弱(间隙大)→谐振裂开、中间出 -10dB 洞。别被"外包络变宽"骗了,必查连续性。
- **多端口/对称结构**:单变量往往是各端口的**跷跷板**(一口变好另一口变差),必须同时看所有端口,别只盯一个。
- **方向图频率稳定性可调但守恒**:某些尺寸(如柱高)只是把"方向图最干净的频点"搬来搬去——设计频优化好可能让**带边方向图劣化**(法向凹陷/波束劈裂)。优化方向图务必**多频点**核对,不能只看设计频。

## 参扫 vs 手工逐点:旋钮已定就用参扫,别手工
- **默认用 `create_parametric_sweep` + `get_parametric_results`**,适用场景是**旋钮已经确定、只差定值**。
  好处有两个,第二个比第一个重要:
  1. 无人值守,省掉每轮"读数→判断→重发"的来回;
  2. **天然一次只动一个变量**。手工逐点时很容易为了省时间在同一轮里改两组变量,
     结果读数无法归因——实测因此丢掉过一个已经调到 −34dB 的工作点,还不知道是哪个变量丢的。
- **代价是中途不能改主意**:第一个点就看出方向不对,剩下的点也得跑完。
  所以**方向未知时先手工单点试探**定方向,方向明确后再用参扫定值。
- **工具调用撞超时上限不致命**:超时的只是 MCP 调用,HFSS 会继续解,结果在磁盘上,
  用 `get_parametric_results` 照样取。曾因为一次"3 组合参扫超时失败"就长期避开参扫——
  那次贵的真正原因是**每个组合里挂了两条存场扫频**,不是参扫本身贵(setup 该怎么挂见 `_solving.md`)。

## 频率类旋钮:线性缩放律很准,先用它算再仿
谐振频率对"谐振体长度"基本是反比线性。实测某臂长 135mm→谐振 1.440GHz,
按 `L_new = L × f_now/f_target` 算出 141.5mm 对应 1.55GHz,实跑 1.556GHz,**误差 0.4%**。
⇒ 频率对不准时**一步算到位**,别二分试探。但**大步长要当心**:同一案例从 135 跳到 141.5(+4.8%)
时谐振直接消失(强耦合结构里该模式散了),小步长(135→138)才平滑。
⇒ 先用线性律算出目标值,再判断步长是否过大;跨度大就分两步走。

### 整体移频要**全尺寸等比缩放**,别对个别尺寸"网开一面"
把一副已定稿天线搬到另一频段,正确做法是**所有长度乘同一个比例因子**(含臂宽、缝宽、地板半径)。
唯一不缩放的是**外部硬约束件**(SMA 内导体直径、同轴口尺寸、板厚这类买来的/工艺定死的)。

⚠️ 踩过的坑:因为 SMA 馈针不缩放,就推断"主臂宽 `wm` 也该保持原值,好维持 针宽/臂宽 比例"。
实测(L 频段 QHA,缩放因子 1.3092)完全相反:

| 主臂宽 wm | 低带 ActiveS | 高带 ActiveS |
|---|---|---|
| 5.95(原值,不缩放) | −6.9 dB | −11.8 dB |
| 6.8(折中) | **−1.6 dB** | −12.2 dB |
| **7.79(等比缩放)** | **−13.0 ~ −13.6 dB** | −12.9 ~ −13.0 dB |

臂宽决定的是**臂的特征阻抗和辐射电导**,属于天线本体电尺寸,必须缩放;
它跟馈针的关系是"抽头位置"问题,该由**馈针径向位置**去补,不是靠改臂宽。
⇒ 缩放后如果只差最后 1~2 dB,先查**馈点/抽头的相对位置有没有跟着缩放**,别去动本体电尺寸。

## 匹配深度卡住时:读输入阻抗,别猜
**判据**:取 `re(ActiveZ(P1:1))`(纯后处理,不用重解)。谐振点虚部过零,实部直接给出失配来源。
实测:某结构谐振深度死活停在 −6.0dB,读出 `re(ActiveZ)=16.7Ω`,
`Γ=(16.7−50)/(16.7+50)=−0.499` 正好 −6.03dB,与实测 −6.01 完全对上。
⇒ 深度不够时先读阻抗定性(欠阻/过阻/纯电抗),再决定动哪个旋钮,比盲扫快一个数量级。

## ⚠️ 别去追小于"仿真重复性"的余量
窄缝、弱耦合结构对网格极敏感:实测 0.17mm 缝的寄生极点,缩放变量只差 0.16% 的三次求解,
极点深度在 −30 / −20 / −12.8 dB 之间**非单调跳动**。
⇒ 此时靠微调找"刚好过线"的点没有意义。判断方法:同一配置换个收敛档位重跑一次,
两次之差就是本模型的重复性下限;**余量小于它的优化结论不成立**,要么加余量要么加密网格。

## 宽带双调谐匹配:dB 曲线中间有个洞,看反射环的环心,别盯着 dB 曲线扫
- 现象:双谐振(叠层贴片/缝隙耦合等)的带内,两个谐振之间有一个 −7~−9 dB 的洞。扫馈线长度、枝节长度,只会让两个谐振此消彼长,洞一直填不上。
- 诊断:取带内复 Γ(get_input_metrics 会把复 S 落盘成 CSV),把带内各点的 Γ 求平均当作环心,换算成阻抗 Zc。
  洞就是环上离原点最远的那一侧。**环的大小合适(半径 < 0.3)时,只要把环心挪到 50 Ω,整条环就自然落进 −10 dB 以内。**
- 解法:按环心偏差分两步选旋钮:先降/升 Re(Zc),用改变馈电耦合强度的量(缝隙耦合的跨缝位置、偏置距离);
  再补 Im(Zc),用串联电抗类的量(开路枝节加长 = 往感性方向补)。实测两轮把洞从 −7.5 dB 补到全带 < −10.5 dB,
  之前三轮单变量扫参都没做到。
- 适用:任何"两个谐振都在、只是没连成一片"的宽带匹配。两个谐振本身没激起来时不适用,那要先看电流分布。

# 渐变槽天线(Vivaldi / LTSA / CWSA / 对踵 AVA / 平衡对踵 BAVA)建模经验

> 设计数据(闭式公式、归一化尺寸、判据)在 `../design/vivaldi-tapered-slot.md`,本文只记**机理与坑**。

## 行波天线"辐射完"的判据是槽宽 ≈ λ,不是 λ/2
- 常说的"频率 f 在槽宽≈λ/2 处辐射"只是**开始**辐射的位置;要**基本辐射干净**得到槽宽≈λ。
- 这条决定两件事:
  1. **板子物理长度下限**:最低频的「槽宽=λ」点必须落在板内,否则波撞硬边反射回来。
  2. **分带截断模型的合法频率下限**:截断处槽宽对应的频率,就是这个模型往下能信到哪。
- 现象(踩过):截断留了「λ/2 点 + 一点余量」就开跑,低频端 S11 纹波被自己造的硬边放大,
  误以为是设计本身匹配差。**算余量要按 λ 点算。**

## 频率↔位置是一一映射,这是分带建模合法的根据
- 指数张开 `slot = wt·e^(p·d)`(d = 距喉部距离),各频率各占一段,互不重叠。
- 所以**超宽带 Vivaldi 必须分带建多个模型**:高频段只需喉部那一小截(网格才付得起),
  低频段才要全尺寸(但低频网格粗,也付得起)。硬要一个模型跨 60:1 会是 10^8 量级四面体,不可解。
- 每段的截断点用上一条的「λ 判据」定,相邻两段留一段重叠频率互相印证。

## 超宽带下基板厚度判据 `t_eff/λ₀` 的**用法**要变
- `t_eff/λ₀ = (√εr−1)·t/λ₀` 正比于 f。带宽 N:1 → 这个量也横跨 N:1,
  而推荐窗 0.005~0.01 只有 2:1 宽 —— **一块基板不可能让全带都落窗内,别浪费时间去凑。**
- 正确用法:**保证带顶不进 E/H 面劈裂档(≥0.018)**,低频端偏薄没关系
  (偏薄=束缚弱=增益低、副瓣低,而超宽带设计的增益通常有大量富余)。
- 即:按**最高频**选基板厚度,低频端听天由命。

## 馈电渐变段长度由**最低频**定,和高频无关
- 对踵/平衡对踵的过渡段本质是阻抗渐变线,反射 `|Γ| ≈ ½·ln(R)·|sinc(βL)|`。
- βL 很小(渐变段远短于 λg)时 sinc→1,`|Γ|→½ln(R)`,**与长度无关地烂**。
- 所以定长度只需拿**最低频**的 λg 去算;高频端 βL 已经几十,自动满足。
- 起手:要 −10dB 取 βL≥1.4;要 −20dB 取 βL≥4.6(即 L ≈ 0.73·λg@f_low)。

## 工具链只有 lumped/coax 端口时,选 AVA(两层)而不是 BAVA(三层)
- BAVA 是**带状线**馈电 = 三导体,lumped port 只有两端子,硬凑会激出寄生平行板模,
  S11 直接不可信(而宽带 Vivaldi 的成败恰恰全在 S11 精度上)。
- AVA 是**微带**馈电(上层带线 + 下层地),lumped port 一步到位,且基板从两张薄板变一张,
  网格负担减半。代价只有交叉极化(−10dB vs −20dB)和几度波束斜视。
- **判断:指标里没写交叉极化/斜视就用 AVA。** 真要 BAVA,馈电得改同轴 + 地过孔围栏。

## 扫频类型:宽带电大结构一律 Discrete
- 口径反射与馈点形成驻波,S11 纹波周期 `Δf = c/(2·L·√εeff)`,
  电大结构在宽带内有几十个极点,插值扫频的有理拟合**原理上追不上**。
- 详见 `_general.md`「插值扫频的第三种失败:静默地无限加点」。

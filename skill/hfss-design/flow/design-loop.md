# 流程:指标驱动设计闭环(正向设计)

> 用户给的是**目标/规格**而非现成尺寸时走这条。照尺寸复现文献不走这条,
> 走 [s-parameters.md](s-parameters.md) + 读图解析。

当任务是"设计一个 X GHz、S11<−10dB、增益≥Y 的天线"或"参考某结构设计一个"——即**正向设计**而非照尺寸复现时,走这条闭环(配合 `capture-learning.md` 设计卡片库):

1. **检索起手**:`search_designs`(传 frequency_ghz/polarization/topology/min_gain_dbi)找匹配卡 → `read_design_card` 取正文看闭式公式 / λ 归一化尺寸。
   **没有匹配卡** → 转 **`hfss-search` skill**(检索文献 → 精读提炼 → 产出「结构理解表 + 起手尺寸」交用户确认)拿到起手值后回本步骤第 2 步;无联网/用户不想查文献时,才退回常规建模 + 收工时新建卡。
2. **缩放**:用卡里的**闭式公式**(优先)或 **λ₀ 归一化常数**算到目标频率/基板的起手尺寸(尺寸 ∝ 1/f;换 εr 必须重算 εeff)。`set_variable` 落成变量再建几何。
3. **搭建 + 求解**:按 §3.5 坐标层叠、§5 sheet 规则、`s-parameters.md` 求解流程建模并 `analyze`。
4. **对标门**:从 `get_s_parameters` / `get_radiation_pattern` 取实测,调 **`check_design_targets`**(measured + targets)拿结构化判定。**这是闭环的客观终止条件,别靠眼估说"差不多达标"。**
5. **不达标 → 定向调**:看 `check_design_targets` 的 `failed_metrics` + 卡的"起手→调匹配"(哪个自由度控哪个指标,通常**频率调辐射体尺寸、匹配调馈电位置**,解耦),对症选**控制变量**走 `tuning.md` 扫参 / `tuning.md` 优化,落最佳值后**重跑 `check_design_targets`**,直到 `all_pass` 或向用户说明卡在哪。
   ⚠️ **选不出控制变量时**:`tuning.md` 灵敏度分析直接给出该动谁(便宜,比粗扫省);
   **扫了一轮方向不对、或根本不知道结构为什么不工作时**,→ `diagnose-current.md` 取电流分布看机理。
   两者分工:灵敏度回答"动哪个旋钮",电流分布回答"为什么不转"。
   "没激励起来"和"激励了但模次不对"要动的东西完全不同,靠猜会把扫参预算烧在错的变量上;
   一次电流诊断用自适应频点的场,不额外花钱。**但别反过来每轮都诊断** —— 扫参阶段要的是指标不是机理。
6. **收工沉淀**:做出达标设计后,按 `capture-learning.md` 把它录成/更新 `design/<type>.md`(归一化尺寸 + 实测 performance + 出处),让卡片库复利增厚。

要点:**先对标再调、调完再对标**,每轮用 `check_design_targets` 闭合;多目标在 targets 里一次列全(频率~=、S11/AR<=、增益/带宽>=),别只盯一个把别的调坏(尤其 `tuning.md` 提的多端口跷跷板、方向图频率稳定性守恒)。

# 流程:本征模求解(不要端口)

> 直接解结构自身的谐振频率与 Q。**要 S 参数/匹配/方向图的一律不走这条**,
> 走 [s-parameters.md](s-parameters.md)——本征模不产出这些。

**什么时候用**(符合任一条就该考虑,别默认一律走驱动求解):
- **腔体 / 滤波器 / 谐振器**要的是谐振频率和 Q,本来就没有"馈电"这回事
- **介质谐振器天线(DRA)**:模式活在介质体内,驱动求解要先猜馈电位置,猜错了模根本激发不出来
- **"这个结构到底支持哪些模"** —— 拿不准该在哪儿馈电、或怀疑激发错了模时,先问结构本身
- **周期结构 / 超表面单元**的本征模

**什么时候不用**:要 S 参数、要匹配、要方向图 —— 这些都需要激励,一律走 `flow/s-parameters.md`。
本征模**不产出** S 参数和远场。

**流程**(和驱动求解是两条路,别混):
1. `new_design(solution_type='Eigenmode')` —— **必须建成本征模 design**,驱动类型的
   design 建不了本征模 setup
2. 建几何。**不加端口、不加激励**;开放结构仍要 `create_open_region`,闭合腔体不需要
3. `create_eigenmode_setup(name, min_frequency, num_modes)` ——
   `min_frequency` 取**略低于**你预期的最低模(给高了会漏掉低阶模);
   `num_modes` 按要看几个模给,**简并模各占一个名额**
4. `analyze`(和驱动求解同一个工具)
5. `get_eigenmodes` 取各模频率与 Q

**读结果的两个要点**:
- **`Q=0` 是无耗,不是出错** —— 真空 + PEC 的理想腔体 Q 无穷大,HFSS 报 0。
  要算真实 Q,材料得有 tanδ 或壁用 `assign_finite_conductivity`
- **`spacing_pct` <1% 基本就是简并模**,做单模器件要确认馈电不会把另一个一起激发

> 本征模比驱动求解便宜得多 —— 没有端口和扫频,通常几秒到几十秒。

## 这张卡做完去哪
拿到本征频率/Q 之后要看**匹配或方向图** → 得另建一个驱动类型的 design,
走 `s-parameters.md`。本征模不产出 S 参数和远场。

# 流程:电流分布诊断(看机理)

> **条件触发,不是每次取结果都做。** 指标已达标、或只是常规扫参找最优值时,不要进这一页。

S 参数和远场只告诉你进去多少、出来多少。失配了不知道是没激励起来还是模次不对、方向图歪了不知道哪部分在辐射时,
用 `get_current_along_path` 看结构上实际流了什么,比接着扫参快得多。

用法:沿要考察的导体画一条采样线,再 `get_current_along_path(path=线名)`。画法照工具描述:
**`create_polyline(non_model=True, close_surface=False, cover_surface=False)`**,线略短于导体、避开馈电点。
- 非模型线不进网格,求解后补画不作废解;画成模型线会让解作废(COM 不报错)。
- 端到端画、穿过馈电点,读到的是馈电区电流,不是谐振模式。

返回的三个判据:
- **`n_nulls`**:内部零点数,模次 = n_nulls + 1
- **`peak_at_fraction`**:峰值在线上的归一位置 → 谐振住在哪
- **`decay_db`**:首尾衰减 → 行波结构辐射完了没

**一条线只在电流路径一维、且你知道它在哪时够用**(谐振天线主模)。下面几种画 3~7 条平行线横向对比:
电流绕缝/拐角走的;要认高阶模(零线是二维图案);检验对称性(四臂、双极化,在对称位置各画一条比 `peak` 和 `n_nulls`);
找意外热点(尖角/缝隙电流异常集中,常是建歪或馈电不对,少数是没收敛)。

## 该看的时候
- S11 不达标但不知道该调哪个变量:分清"根本没激励起来"(整体电流都很小)和"激励了但模次不对"(`n_nulls` 不对)
- 谐振频率对、方向图不对:多半激发了错的模式
- 寄生/耦合单元有没有工作:寄生件电流只有主辐射体的个位数百分比 = 没被激励,调它的尺寸是白费
- 多谐振结构"谁负责哪个谐振":两个谐振频点各取一次
- 行波/渐变槽"辐射完了没":沿槽看 `decay_db`
- 怀疑弱接触/建歪:电流在接缝处断掉是直接证据

## 不要看的时候
- 指标已达标;常规扫参找最优值的过程中(要的是指标不是机理)
- bbox / `validate_design` 自检没过,或自适应没收敛 —— 场不可信,先修

## 代价
默认 `sweep='LastAdaptive'` 用自适应频点的场,总是在、不额外花钱,优先用它。
看别的频点要存场扫频,只建要看的那一个频点,看完 `delete_sweep`。

## 这张卡做完去哪
- 诊断出机理、知道该动什么 → 回 `tuning.md` 定向调
- 按机理改过再两轮仍没少项 → 停,交给用户(见 `SKILL.md` 卡住了怎么办)
- 发现是几何建错 → 回 `s-parameters.md` 几何自检那步
